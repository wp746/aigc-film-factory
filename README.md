# AIGC 制片工厂 · 4.0

一套按影视工业流程搭建的 AI 出片框架。从一句创意、一个类型想法或一份现成剧本出发（单片或剧集，剧集见 [docs/22](docs/22-剧集模式.md)），用户只在故事、剧本、出图花费、出视频花费四处点头；剧本确认后，自动化流水线跑完资产、出图、白模预演、零抽卡闸门，交付：

1. **《资产提示词》**（`交付/01-资产提示词.md`）：人物三视图、场景、道具、群像，每张图标好推荐出图模型和美术要求；默认用 Image 2.5（APIMart 2K）批量出图。
2. **投喂包**（`交付/投喂包/<模型>/第N条/`）：每条一份，含提示词、参考图接线、白模预演视频（`@视频1`）、界面参数。同一份镜头规格单编译到 **Seedance 2.5 / 海螺 H3 / 万相 3.0**，各按官方格式写。

立项先挑类型和时长：[docs/21-类型片库与时长档位.md](docs/21-类型片库与时长档位.md)（29 张类型卡、6 个时长档位与估价）。最高标准见 [docs/20-顶级标准.md](docs/20-顶级标准.md)：不做等救主式电子垃圾，每条有价值翻转、视听高光和张力。框架成熟度与已知短板见 [docs/12-框架审核评估.md](docs/12-框架审核评估.md)。

## 安装

```bash
git clone <本仓库地址> aigc-film-factory
cd aigc-film-factory
./install.sh            # 把本仓库作为 skill 链接进 Claude Code / Codex / CodeBuddy 的 skills 目录
cp .env.example .env    # 填你有的出图 API 密钥（填一家就能跑）
python3 tools/pipeline.py selftest examples/样例-便利店   # 自测：不花钱，产物和标准逐字一致才算装好
```

| 智能体 | 怎么用 |
|---|---|
| **Claude Code** | 在仓库目录里打开即可（读 `CLAUDE.md`）；或 `install.sh` 后在任何目录用 `aigc-film-factory` skill |
| **Codex** | 在仓库目录里打开（读 `AGENTS.md`）；或 `install.sh` 后作为 skill 加载 |
| **WorkBuddy / CodeBuddy** | 支持 SKILL.md 格式 skill 的版本：`./install.sh <它的 skills 目录>`；不支持的版本把仓库作为工作目录，让它先读 `SKILL.md` |
| **其他智能体** | 把仓库作为工作目录，或把 `SKILL.md` 的内容作为系统提示词，并允许它读写本仓库文件、运行 `python3` |

依赖：Python 3.9+（`pip install pillow`）；白模预演需要 Blender 4.x 和 ffmpeg；审片听写可选 `faster-whisper`。

## 用法

对智能体说 `~start 我的项目名`，或者"帮我出几个故事创意""这是我的剧本，做成视频提示词"。剧本确认后它会：

```bash
python3 tools/storyboard.py check projects/<项目>     # 校验 设定.json + 分镜.json
python3 tools/pipeline.py run projects/<项目>         # 跑流水线，停下时最后一行 NEXT 就是下一步
python3 tools/pipeline.py status projects/<项目>      # 看进度
python3 tools/pipeline.py qc projects/<项目> 第1条 <视频>   # 出片后审片机检
```

## 流程

```
① 故事 → ② 剧本（世界观与美术设定 + 剧本 + 节奏曲线）
→ 设定.json + 分镜.json → 校验
→ 资产提示词 → ③ 批出图预算 → 出图 → 资产目检 →（可选）角色压力测试
→ 镜头规格单 → 白模预演 → 规格自检 → 几何检查 → 逐帧拼图 → 白模目检
→ 四模型投喂包 → 报告 → ④ 批出视频 → 出片 → 审片 → 剪辑混音 → 复盘写回规则
```

## 岗位（26 个）

默认模式下，岗位是拆数据时必须过一遍的视角，检查由流水线的机检和目检完成；标"审"的岗位和门禁只在完整模式里作为独立环节。

| 阶段 | 岗位 | 负责 |
|---|---|---|
| 统筹 | 00 总制片人 | 立项、选模式、跑流水线、预算授权、交付、复盘 |
| 参考 | 16 风格参考总监 | 参考片拆成叙事、视听、表演、声音四层；从风格库选画风 |
| 故事 | 01 故事架构师 / 02 编剧 / 03 剧本医生（审） | 故事内核与分条；电影级剧本、台词五招；对抗式审稿 |
| 导演 | 04 总导演 | 调性、视觉论点、每条视听高光、白模目检签字 |
| 视觉开发 | 05 摄影指导 / 06 美术指导 / 07 角色造型师 | 焦段、光、有动机的运镜；锚点物、光逻辑、对冲、道具机制；描述锁、剪影、三视图、压力测试 |
| 表演与声音 | 08 表演指导 / 09 声音导演 / 23 台词对白导演 | 手上的动作与反应链；音色锁、声源在画里；台词五招与容量 |
| 资产 | 19 Image 2.5 资产提示词大师 / 20 资产主管 | 资产提示词总册；出图、目检、定版 |
| 分场与分镜 | 22 文戏导演 / 17 武戏导演 / 18 VFX 导演 / 10 分镜师 / 25 白模预演导演 | 调度与覆盖、动作因果、特效七要素；分镜数据；白模 |
| 编译与检查 | 11 编译师 / 12 场记（审）/ 21 提示词质检（审）/ 14 合规官（审） | 四模型投喂包；连续性；出片前对抗审查；合规 |
| 出片后 | 13 审片质检（审）/ 15 剪辑调色 / 24 后期声音与混音 | 24 分审片；剪辑调色；对白清理、配乐、混音 |

## 三种模式

- **默认模式**：用户点头四次，流水线跑到交付，见 `docs/09`、`docs/18`。
- **完整模式**：26 个岗位轮流交稿、9 道门禁两步审核，见 `docs/01`。
- **精简模式**：30 秒–5 分钟，18 个席位，见 `docs/08`。
