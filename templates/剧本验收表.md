# 剧本验收表（好莱坞式 coverage × 工厂标准）

> 2026-11-07 立（4.0 alpha.9）。来源：好莱坞读稿员 coverage 的结构（前提、故事、人物、对白、结构、节奏、调性、市场性；结论分 PASS / CONSIDER / RECOMMEND），加上资料库里两个机制：review-checklist 的"⭐ 关键项一票否决、每项附检验方法"，以及剧本医生圆桌的"只标分歧、不打均分"。详细写法见 `docs/23-剧本写作法.md`。
>
> **谁用、什么时候用**：
> - 执笔人：剧本交用户确认（② 剧本确认）之前，自己逐项过一遍；
> - 冷读子代理：`pipeline.py coldread <项目> 故事` 时拿它读稿；
> - 剧集：全季故事过一次，每集剧本过第二、三、五、七段。
>
> **不开审核会、不出评分报告、不退回**（默认模式，docs/09）。过不了的项就地改，改不了的写进交给用户的那一页里。

---

## 结论三档

| 结论 | 条件 | 怎么办 |
|---|---|---|
| **RECOMMEND** | ⭐ 全过，非 ⭐ 最多 1 项不过 | 交用户确认 |
| **CONSIDER** | ⭐ 全过，非 ⭐ 2–3 项不过 | 改完再交；改不了的在交稿时说明 |
| **PASS（退稿）** | 任一 ⭐ 不过 | 不交，回到故事或剧本阶段 |

## 一、前提与内核（和 docs/20 第三节 A–H 合并，不重复）

| | 项 | 检验方法 |
|---|---|---|
| ⭐ | 一句话梗概：身份或处境 + 核心矛盾 + 转折契机，50 字内 | 念给一个没看过的人，他能复述吗？ |
| ⭐ | 有一个锋利的"如果"，它的规则在第几秒交代 | 指出那一秒 |
| ⭐ | 两难是双输：做 A 失 X，不做失 Y（`core.dilemma`） | 主角有没有一条不付代价的出路？有就不合格 |
| ⭐ | 内核闸门 A–H 全过；F（等救主）一票否决 | 逐条写过 / 不过 |
| □ | 情绪承诺：一句话说清观众看的是什么感（`core.promise`），全片兑现了吗 | 每条往这个感觉上加码了吗？ |
| □ | 母题：用了一个大众能共鸣的母题（docs/23 第一节、docs/11 货架 E），主角是主动改写它的人 | 说出母题和改写点 |
| □ | 有一个观众没想到、但信服的真相 | 说出来，问自己"信吗" |

## 二、结构

| | 项 | 检验方法 |
|---|---|---|
| ⭐ | 3 秒内有视听钩；15 秒内能说出"谁、想要什么、被什么挡住" | 只看前 15 秒的文字，写出这三样 |
| ⭐ | 每一条（场）都是一次价值翻转 | 列出每条开头和结尾的价值，一样的就是空场 |
| ⭐ | 递进，不是并列 | 删掉任一条，后面还立得住吗？立得住就删或合并 |
| □ | 节拍按时长档位踩点：激励事件、中点大翻面、最低谷、高潮（docs/21 第三节） | 标出各在第几条 |
| □ | 大翻转大约落在全片 1/4、1/2、3/4 | 标出位置 |
| □ | 功能标签（`tag`）不连续 3 个相同 | 列出标签序列 |
| □ | 结尾三件事：代价呈现、关系新平衡、照应开场意象；不说教，不全员和解；最后一镜是画面 | 指出各在哪一镜 |

## 三、冲突与反转

| | 项 | 检验方法 |
|---|---|---|
| ⭐ | 冲突落在主角身上，每一级威胁都由对手抬高赌注 | 列出威胁阶梯 |
| ⭐ | 反转有伏笔 | 列"埋设条 → 回收条"表（`foreshadow`），回收没有埋设就是巧合 |
| □ | 施力足够：反转前的压力和损失够真 | 删掉反转前一条，反转还那么爽吗？还爽说明没施够力 |
| □ | 信息差明确：悬念、惊奇、双关各在哪一条 | 每条 `tension` 写了哪一种 |
| □ | 每个爽点都带代价 | 指出代价 |
| □ | 反转之后回头看第一条，意义变了 | 写出变化 |

## 四、人物

| | 项 | 检验方法 |
|---|---|---|
| ⭐ | 主角的欲望具体可见：一个东西、一个数字或一个期限 | 写出来 |
| ⭐ | 主角第一个动作立人设，不靠台词或旁白介绍 | 指出那个动作 |
| □ | 压力写成数字 | 写出数字 |
| □ | 对手有自己的正当性，不降智 | 替对手写一句自辩 |
| □ | 配角各有功能（施压、共情、对立、见证） | 合并两个配角会丢信息吗？不丢就合并 |
| □ | 弱者和女性有自己的欲望（闸门 G） | 写出她想要什么 |
| □ | 有名字的人都写到结局 | 逐个列 |

## 五、对白

| | 项 | 检验方法 |
|---|---|---|
| ⭐ | 遮名测试：主要角色八成以上台词遮住名字也认得出是谁 | 随机抽 10 句盖名字 |
| ⭐ | 没有灌输：不写"你忘了吗，三年前……"，不自报家门，不让旁白替人说心理，不把潜台词说成台词 | 逐句找 |
| □ | 每句都推进：说完至少一项变了；连续 3 句没变化就删 | 删字测试、替换测试 |
| □ | 潜台词：关键戏至少一处说的和想的相反，用动作透出来 | 指出那一句和那个动作 |
| □ | 槽和梗：至少一处用称呼或一句话完成地位翻转；每场最多一句只属于这个人的狠话 | 把狠话换给别人说，还成立吗？成立就不是他的 |
| □ | 至少一条结尾停在台词钩子上（半句话、反常陈述、翻局的话） | 指出那一句 |
| □ | 说得出口：台词五招（crew/23），每秒不超过 4.5 字，单句不超过 20 字，连续 3 句不一样长 | 校验器会提醒一部分 |
| □ | 类型语感对，职业说职业话 | 找串戏的词 |

## 六、视听与可生成性（对接 docs/20 第二、四节）

| | 项 | 检验方法 |
|---|---|---|
| ⭐ | 静音测试：把台词全删掉，只看动作和画面描写能懂一半 | 删掉台词读一遍 |
| ⭐ | 没有情绪标签：全文找"悲伤、痛苦、愤怒、紧张、难过、绝望……"，每一处都换成看得见的动作或停顿（docs/23 第二节第 7 条） | 全文搜情绪词 |
| ⭐ | 每条有视听高光；每个慢段至少承担一项功能（docs/23 第五节第 4 条） | 逐条指出 |
| □ | 至少一个截图能传播的奇观，是 AI 擅长的那种 | 指出那一镜 |
| □ | 复杂度在预算内：同框追踪不超过 3 人，动作拆短镜 | 对照 docs/06 |
| □ | 世界至少 5 个只属于它的细节；承载物不是默认的纸条、钥匙、照片、信封，或者用出了新意义 | 列出细节 |

## 七、节奏与留存

| | 项 | 检验方法 |
|---|---|---|
| ⭐ | 没踩五条节奏红线（docs/23 第五节第 5 条） | 逐条对 |
| □ | 能量曲线热冷交替；最后一镜最冷或最响 | 看 `energy` |
| □ | 剧集：冷开场接住上集钩子；`hook_type` 同类不连用 3 次；压抑不超过 3 集；前 3 集各有一次大翻转 | 看 `季.json` |

## 八、合规

| | 项 | 检验方法 |
|---|---|---|
| ⭐ | 没有擦边、性暴力当钩子、民族情绪当爽点、真人真品牌；不用广电总局点名的"霸总娇妻、豪门赘婿"一类套路 | 对 crew/14 清单 |
| □ | 未成年、IP、暴力尺度按合规官清单 | crew/14 |

## 输出格式（一页）

```markdown
# 《片名》剧本验收（第 N 稿，日期）

结论：RECOMMEND / CONSIDER / PASS

⭐ 不过的项
- [位置：第3条 镜2] 原文"……" → 违反：五、没有灌输 → 改的方向：……

非 ⭐ 不过的项
- ……

写得好、别动的
- ……

执笔人自己最不满意的一处
- ……

（冷读时加）分歧：视角 A 认为……，视角 B 认为……
```
