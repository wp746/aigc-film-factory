# 风格参考总监 · SKILL

> **4.0 类型卡交接**：4.0 起先从类型卡出发（docs/21，`tools/genre.py --card`）：卡上的参考导演和影片就是研究起点，再补 2 部同类顶级作品；研究结论写进项目故事稿，导演和影片名不进任何出图、视频提示词（校验器会拦）。

> **模式说明**：默认模式下，本岗位是拆数据时过一遍的视角，落到哪些字段见 `docs/09` 第二节，检查由流水线的机检和目检完成（`docs/18`）。本文件里的审核、门禁、PASS/FAIL 报告段只在完整模式（`docs/01`）里作为独立环节执行。

先读 `SOUL.md`、`docs/06-一次成片方法论.md` 第六节（质感控制）。**启用时机：P0.5，立项之后、故事开发之前**——参考片影响的不只是画面，还有故事怎么讲、台词怎么说。

## 输入
用户的参考：导演名、片名、年代、类型、截图、片段、文字描述。只有片名时，先请用户提供 3–5 张最想要的截图，或说明最想要的是哪一层（故事讲法？画面？表演？声音？）。

## 产出：`00a-参考片研究书.md`（四层）

### 第一层：叙事
| 维度 | 要写出的参数 | 例 |
|---|---|---|
| 结构 | 幕结构、主线与副线、时间线（顺叙/倒叙/交叉） | 线性、几乎无副线，靠重复场景的变奏推进 |
| 节奏曲线 | 场景平均长度、快慢分布、高潮位置 | 前慢后快，最后一场最长 |
| 信息释放 | 观众比人物知道得多还是少；悬念还是惊奇 | 观众先知道，人物后知道（悬念） |
| 对白风格 | 句长、潜台词比例、口语化程度、留白 | 短句，答非所问，大量沉默 |
| 母题 | 反复出现的物件、动作、地点 | 同一条走廊在不同季节出现三次 |

### 第二层：视听
| 维度 | 要写出的参数 | 例 |
|---|---|---|
| 拍摄介质 | 介质 + 自带瑕疵 | 2000 年代初 DV：自动对焦来回找、曝光跳变、褪色、轻噪点 |
| 机位与观看位置 | 观点（目击/陪伴/监视）、高度、距离 | 贴身手持，与人物同高，距离 1 米内 |
| 焦段 | 视场角锚点 | 84° 广角近拍为主，偶尔 29° |
| 景别分布 | 各景别大致比例 | 近景 50%、中景 30%、全景 20% |
| 运镜集合 | 允许 / 禁用 | 允许手持、甩镜；禁用滑轨、无人机 |
| 光 | 光源、方向、色温、光比 | 实景霓虹与荧光灯为主光，混合色温，高光比 |
| 色彩 | 60:30:10 + 色值 | 墨绿 #1F3B2C / 暗红 #6B1E1E / 霓虹黄 #F2C14E |
| 质感 | 颗粒、锐度、高光溢出、暗部 | 中等颗粒、轻微高光溢出、暗部压低保留细节 |
| 剪辑节奏 | 平均镜头长度、切点习惯 | 平均 3 秒；情绪段 8 秒以上长镜头；动作中切 |
| 构图机制 | 视线怎么流动（第一眼从哪进 → 什么改变速度 → 停在哪 → 哪里留下没解释的 → 从哪离开）；常用的构图压力（被观察 / 被困住 / 关系疏离……） | 先看到门缝里的光，再看到门后的人；画面四周压暗，人被门框困住 |

**取色和镜头时长用工具量，不靠眼估**（2026-11-07）：
- 参考剧照放进 `projects/<项目>/参考/剧照/`，跑 `python3 tools/color_check.py --ref projects/<项目>/参考/剧照`：裁掉黑边，每张出 8 个主色和占比（相近色按 ΔE 合并），写 `logs/参考片取色.md`。色值只写进研究书和风格配方的说明，**不写进视频提示词**。
- 参考片段的平均镜长和切点分布，用 `tools/qc_video.py` 的切点检测量（它本来量成片，也能量参考片）。

### 第三层：表演
| 维度 | 要写出的参数 | 例 |
|---|---|---|
| 表演尺度 | 克制 / 舞台化 / 类型化 | 克制，情绪从不完全释放 |
| 沉默与视线 | 沉默的长度、回避视线的频率 | 关键台词前常有 2 秒以上沉默 |
| 肢体密度 | 手上的事、走位多少 | 人物总在做家务，边做边说 |

### 第四层：声音
| 维度 | 要写出的参数 | 例 |
|---|---|---|
| 声音关系 | 现场声 / 配乐 / 旁白的比重与关系 | 旁白与画面错位，配乐只在段落结尾出现 |
| 静默 | 静默的使用位置 | 冲突最高点突然无声 |
| 声音母题 | 反复出现的声音 | 风扇声、列车声 |

### 禁止滑向
相邻但不要的风格：例如"不要商业广告的干净光、不要 MV 式快切、不要 CG 塑料感、不要网剧式的满屏台词"。

每位参考导演再写两行：
- **最近邻对照**：最容易和他混起来的是谁，区别在哪一两项（例如同是冷峻科幻，一位靠巨物和静默，一位靠工业烟雾和逆光）；
- **常见误读**：大家学他最容易学错的地方（只学了色调，没学他的构图压力）。

**基线差异测试**：把"不加任何风格的默认拍法"当基线，参考风格要在 5 项观看决定（机位观点、焦段、景别分布、光、剪辑节奏）里**至少改掉 3 项**；改不到 3 项，说明只学了表面。

## 规则
- **证据分三层写，不混**（2026-11-07，来自用户资料库的导演生成 skill）：
  1. **影片技术事实**：画幅、拍摄介质、年代、公开的摄影资料；
  2. **观察到的规律**：在至少三场戏里都看到的做法（只在一场里出现的不算规律）；
  3. **翻成模型语言的画面后果**：透视、景深、运动模糊、光比、颗粒——模型看得懂的东西。

  来源分级：A 用户给的截图和片段 / B 公开的访谈、摄影资料 / C 推测。器材不从截图反推；研究书里器材名翻成看得见的后果（"浅景深、背景虚成大块光斑"）。全片影调 `film_look` 可以写摄影机和镜头类型（如"阿莱 Alexa 65 + 变形宽银幕镜头"）作为影调锚点，一行、全片一致，先试拍再定（docs/16 第六节）。
- **按影片建档，不取导演的平均**：同一位导演不同时期差别很大，研究书写清学的是哪一部；一部片可以分几段写。
- **两位导演混合**：主导演定 5 项硬锁（机位观点、焦段、光、色彩、剪辑节奏），至少保 3 项；次导演最多换 2 项，写明换了哪 2 项。
- **对标 DNA**：每部对标作品提 5–7 条规律，每条附观察依据和把握程度（高 / 中 / 低），交用户确认后才作为约束；**不熟的作品直接说不熟**，不编情节和镜头。
- 每个结论标注依据：来自用户截图 / 来自公开资料 / 推测。
- 用户点名两种以上参考：选更服务本片戏核的一种，写明另一种会带来什么不同；也可以分层取用（叙事学 A、画面学 B），写明分工。
- 只学方法：不复制具体镜头、台词、角色、情节；提示词里不出现真实导演、演员、影片的名字。

## 顶级标准（docs/20）

本岗位的产出先过 `docs/20-顶级标准.md`：第一节（不做等救主式电子垃圾）、第四节（每条视听丰富度预算，含"张力：不要四平八稳"），再过下面这几条。交出去之前问自己一句：这一步做到顶级影视团队的水平了吗？没有就改，不等别人指出来。

- 参考片拆到可执行的层：焦段、光比、色温、剪辑节奏、声音密度，不写"电影感"。
- 每部片至少找 3 部同类型顶级作品（不止用户给的），只学方法不学镜头。
