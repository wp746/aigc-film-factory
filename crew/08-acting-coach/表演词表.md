# 表演词表（表演指导参考）

> 2026-11-07（4.0 alpha.9）。来源：用户资料库里的微表情 skill（FACS 动作单元、表演三轴）、表演提示词手册（32 组逐秒情绪链、双人戏）和"剧本转 Seedance 分镜"skill（情绪变体）。只收方法，改写成工厂的防崩写法：**情绪交给上半张脸和下颌，嘴自然闭合**（docs/02 第七节、crew/08 D 节）。嘴部的动作单元只在不说话、不靠近镜头时少量使用。

## 一、上半脸和下颌的动作单元（FACS）

| 编号 | 动作 | 写法 | 常用在 |
|---|---|---|---|
| AU1 | 内眉抬起 | 眉头内端微微上提，眉间出现浅竖纹 | 伤心、求助、委屈 |
| AU2 | 外眉抬起 | 眉梢上挑；只挑一边时是怀疑 | 惊讶、怀疑 |
| AU4 | 眉间下压 | 眉头锁紧往下压，眉间纵纹 | 愤怒、专注、困惑 |
| AU5 | 上眼睑抬起 | 眼睛睁大，露出更多眼白 | 惊恐、震惊 |
| AU6 | 脸颊抬起 | 脸颊抬高，外眼角细纹 | 真笑（没有这一项的笑是假笑） |
| AU7 | 眼睑收紧 | 下眼睑绷紧上提，眼睛变窄 | 审视、压怒、强忍 |
| AU9 | 皱鼻 | 鼻梁起皱，鼻翼上提 | 厌恶 |
| AU17 | 下巴上推 | 下巴往上顶，下巴皮肤起皱 | 强忍哭、倔强 |
| AU43 | 闭眼 | 慢慢闭上 / 快速闭上 | 承受、放弃、反转开关 |
| AU45 | 眨眼 | 单次快眨；连续快眨 | 紧张、说谎、回神 |
| — | 咬肌绷紧 | 腮边的肌肉鼓起一下 | 压怒、下决心 |
| — | 喉结滚动 | 吞咽一次 | 把话咽回去、害怕 |
| — | 鼻翼张开 | 吸一口气，鼻翼撑开 | 怒火上来、强忍哭 |

## 二、靠得住的复合表情

| 表情 | 组合 |
|---|---|
| 真实、克制的愉悦 | 脸颊抬起 + 外眼角细纹，眉间放松；嘴角只微微上扬、闭着 |
| 假笑 | 嘴角上扬，但脸颊不抬、眼睛不变 |
| 蔑视 | 单侧嘴角收紧，另一侧不动；眼皮半垂 |
| 强忍的哭 | 内眉抬起 + 下巴上推 + 喉结滚动；眼眶湿但不落泪 |
| 压住的怒 | 眉间下压 + 眼睑收紧 + 咬肌绷紧；呼吸变浅 |
| 麻木 | 所有动作幅度减半，眨眼变慢，视线不聚焦 |
| 怀疑 | 一侧外眉抬起，眼睑微收，头微侧 |

## 三、笼统的情绪先拆成变体

写"他很惊讶"之前，先问是哪一种：

| 情绪 | 变体 | 怎么写 |
|---|---|---|
| 惊讶 | 轻微的意外 | 外眉轻抬，眨一下眼，身体不动 |
| | 震惊 | 上眼睑抬起，呼吸停住，手上的动作冻住 |
| | 不信 | 眉间先皱、再抬，视线来回确认两次 |
| | 惊喜 | 脸颊抬起，往前倾半步，眼睛亮起来 |
| 愤怒 | 爆发 | 鼻翼张开，肩膀往前顶 |
| | 冷怒 | 不动，眼睑收紧，声音反而变轻 |
| | 委屈的怒 | 内眉抬起 + 咬肌绷紧，眼眶红 |
| 悲伤 | 崩溃 | 呼吸先乱，然后肩膀塌下去 |
| | 克制 | 视线移开，吞咽，手抓紧一样东西 |
| | 迟到的悲伤 | 先平静地做完一件事，做完之后才停住 |
| 害怕 | 惊吓 | 上眼睑抬起，整个人往后缩 |
| | 恐惧 | 呼吸浅而快，视线锁死在威胁上 |
| | 焦虑 | 小动作变多：摸东西、看门、眨眼快 |
| 羞耻 | 被当众说破 | 视线先在桌面上找不到落点，然后去整理本来就整齐的东西；轻笑一下但脸颊不动；回答突然变快变短 |
| | 想躲开注视 | 头颈往回收，身体占的地方变小；借一个动作（拿水、转身找东西）退出别人的视线 |
| 内疚 | 想道歉不敢靠近 | 走到两步外停下，抬起的手没碰到对方又收回；说一句短的承担的话，然后不再解释 |
| | 面对后果 | 看见受伤的人时手上的动作慢下来，准备好的话在第一句前没说出来 |
| 嫉妒 | 掩饰 | 视线在对方和比较对象之间来回一次；嘴角保持着笑，下眼睑却收紧；夸奖的话说得太快 |
| 思念 | 被日常物件触发 | 手碰到对方留下的东西时停住，拇指在上面擦一下；放回去的时候比拿起来慢 |
| 释然 | 确认之后才放下 | 先再确认一次（再看一眼、再问一句），然后肩膀落下来，长出一口气，手松开一直攥着的东西 |

## 四、情绪链（按情绪命名的逐拍链，每拍一个动作 + 一个表情变化）

1. **落泪**：瞳孔先失焦 → 想撑住，下巴上推 → 眼眶兜不住 → 一滴落下 → 含着泪笑一下 → 不再装了。
2. **吃着东西想起一个人**：正常地吃 → 咀嚼慢下来 → 停住，视线落在空处 → 继续吃，吃得更快 → 吞不下去。
3. **冷笑自嘲**：麻木地听 → 眼皮半垂 → 一侧嘴角动了一下 → 呼出一口短气 → 视线移开。
4. **面具剥落**：温和地应对 → 一句话之后眼神先冷下来，脸还在笑 → 笑慢慢收住 → 下颌放平 → 声音变轻。
5. **隐忍的怒（男性常用）**：手上的动作停住 → 咬肌绷紧 → 鼻翼张开、吸气 → 压住，慢慢呼出 → 手重新动起来，比之前重。
6. **认出一个人**：视线扫过去 → 回来，停住 → 眉间先皱（不确定）→ 外眉抬起（确认）→ 呼吸停一拍。
7. **说谎被看穿**：眨眼变快 → 视线往下 → 手去碰脸或衣领 → 抬眼，试图对视 → 先移开的是他。
8. **下决心**：犹豫，视线在两样东西之间 → 闭眼 → 呼吸沉下去 → 睁眼，视线锁死 → 手动了。

## 五、情绪和镜头

| 情绪时刻 | 镜头怎么配合（交 crew/05） |
|---|---|
| 隐忍的痛 | 呼吸停住时，缓慢推近 |
| 失望 | 轻微后退，人周围的空白变多 |
| 压住的怒 | 咬肌绷紧时推进，然后锁住不动 |
| 温柔 | 不推不拉，固定长停 |
| 麻木 | 不推进，光平一点 |
| 诀别 | 缓慢后拉，人越来越小 |
| 震惊 | 开头严格静止，半秒后极慢推近，总共只走十几厘米 |

规则：每次运镜服务一个情绪节点，完成就停。

## 六、声音里的表演（交 crew/09）

声音写具体：不是"雨声"，是"雨滴打在伞面上的闷响"。表演的微声音——吞咽、鼻腔吸气、布料摩擦——写进情绪的那一拍。
