# 真人对话数据：反应时序与"内心 → 看得见的表现"（4.0 alpha.13）

来源：Meta 的 Seamless Interaction 数据集（4000 多小时两人面对面对话，演员即兴 + 普通人自然对话，逐帧面部动作单元、头部姿态、逐字时间轴，以及旁观者标注"他当时心里怎么想 / 为什么这么判断 / 画面上看得到什么"）。
许可 CC-BY-NC 4.0（非商用）：这里只用**统计数字和归纳出的规律**，不使用它的视频、动作数据和原文标注。
样本：60 对对话（演员即兴 30 对、自然对话 29 对）做统计；1663 段旁观者标注（4959 组"内心 / 理由 / 画面"三句）做词表。统计脚本不在仓库里，方法写在第三节。

## 一、反应时序（写表演块、台词时间表、提示词时间轴时用）

| 现象 | 数字（中位，括号里是四分之一到四分之三的范围） | 写法 |
|---|---|---|
| 听者的反应**先于**对方句子结束 | 句末前 0.2–0.4 秒脸和头就开始动（演员 −0.37 秒，自然 −0.20 秒） | 反应写在对方这句台词的最后几个字上，不写在台词之后 |
| 点头的位置 | 落在对方的断句处（0.0 / +0.17 秒，大多在断句前后 0.5 秒内） | 点头跟着对方的停顿走，不匀速点 |
| 点头频率 | 听的时候每分钟 7–12 次；说的人自己每分钟 16–22 次（强调时点） | 听者一镜里点一两下就够；说话人在重音字上点 |
| 视线移开 | 说话时约 20% 的时间偏开头 / 视线；听的时候只有 5–10% | 说的人想词、回忆时看别处，听的人基本看着对方；听者频繁移开视线 = 心不在焉或在躲 |
| 眨眼 | 说话时每分钟约 22 次（2–3 秒一次）；专心听时 9–17 次 | 一镜里不能一次都不眨（AI 脸）；专注、对峙时眨得少，紧张、怀疑时眨得多 |
| 笑 | 真正笑开只有 0.8–1 秒；从开始到最满要 1.4–2.4 秒 | 笑是慢慢起来、很快收住，不是一下咧开再一直挂着 |
| 接话间隔 | 自然对话 0.5 秒（−0.3 到 1.7）；演员即兴 0.04 秒，四分之一的接话重叠 1 秒以上 | 普通对话接话留半拍；吵架、抢白写成重叠；超过 1.5 秒的停顿就是"明显的沉默"，要有理由 |
| 句中停顿 | 0.6 秒（0.4–1.1） | 台词里的逗号、省略号按 0.4–1 秒算进容量 |

## 二、内心 → 看得见的表现（写 acting.leak、表演块时从这里挑）

每类按出现频率排序；括号里的百分比是在这一类标注里提到这个表现的比例（多数标注只写一两个表现，所以单项都不高）。**写的时候挑两三个看得见的，不写情绪词本身。**

| 内心 | 最常见的表现 | 容易混淆时的区分点 |
|---|---|---|
| 专注倾听 | 点头（19%）、歪头（19%）、嘴角微微上扬、眉毛轻抬；看着对方 | 和"共情"比：点头多、身体不前倾 |
| 开心、被逗乐 | 笑（54%）、歪头、手跟着比划、点头 | 真笑带面颊上提；只有嘴角动是客气 |
| 生气、不满 | 皱眉、把脸转开、叹气、手往下压 / 挥 | 和"防御"比：生气会把脸转开再转回来盯着；防御是一直躲 |
| 惊讶 | 眉毛上抬（24%）、眼睛睁大、嘴张开、身体往后一仰 | 惊讶只有一瞬，之后是消化（见 SKILL.md C 节） |
| 自信、笃定 | 手势有力（19%）、肩膀打开、点头、偶尔看别处想下一句 | 手势落在重音上；不摸脸 |
| 困惑 | **皱眉最明显（33%）**、视线移开、歪头、挠头、手心翻上翻下 | 和"怀疑"比：困惑皱眉更重、会挠头 |
| 共情、关心 | 点头（25%）、轻皱眉、歪头、身体前倾、叹气 | 和"倾听"比：会前倾、会叹气 |
| 尴尬、不自在 | **笑着同时移开视线**、歪头、摸头发 / 耳朵 / 下巴（17%） | 笑 + 自我触碰 + 往下看，三样同时出现 |
| 紧张、焦虑 | 歪头、视线乱飘（24%）、皱眉、自我触碰（搓手、捏拇指、摸脸）、眨眼变多 | 和"尴尬"比：不笑，手停不下来 |
| 伤心、失落 | 头低下去、闭眼、视线移开、手抱住自己的胳膊、摇头 | 动作变少变慢 |
| 怀疑、不信 | 轻皱眉（25%）、歪头（24%）、眉毛一高一低、摸下巴、眨眼变多 | 视线不躲，盯着对方看 |
| 思考、回忆 | **视线移开最多（32%，往上或往旁边）**、手在空中比划 | 和"走神"比：会回到对方脸上 |
| 防御、抵触 | 视线移开（27%）、耸肩（13%）、手心朝外举起、塌肩 | 身体往后，不看对方 |
| 无聊、走神 | 看别处（27%）、长出一口气、摸脸、打哈欠 | 头和身体都不再朝向对方 |

## 三、方法（复现用）

- 时序：用逐字时间轴把台词合成句段（字间停顿超过 0.6 秒就断开）；头部俯仰在 0.4 秒窗内先低后抬、幅度超过 3° 记一次点头；眨眼取"闭眼"动作单元超过个人 95 分位的上升沿；视线移开取头部水平转角偏离中位 10° 以上；笑取"嘴角上扬 + 面颊上提"超过个人范围一半；反应取对方句末前后面部动作单元和头部变化之和首次超过个人 80 分位的时刻。
- 词表：旁观者标注的"内心"按关键词归成 14 类，在同一段的"画面"和"理由"里数 19 种可见表现。
- 局限：都是坐着面对面聊天，没有走位、动作、群戏；演员即兴偏夸张、接话更快。数字用来定"大概多少"，不当精确参数。
