# 表演指导 · SKILL

> **模式说明**：默认模式下，本岗位是拆数据时过一遍的视角，落到哪些字段见 `docs/09` 第二节，检查由流水线的机检和目检完成（`docs/18`）。本文件里的审核、门禁、PASS/FAIL 报告段只在完整模式（`docs/01`）里作为独立环节执行。

先读 `SOUL.md`；规则以 `docs/02-Seedance2.5提示词圣经.md` 第七节为准。

## A. 表演母本 `07-表演母本.md`（每个反复出场的角色一段）

**150–220 字，一段连续的话，全部可观察可拍摄。** 块顺序固定：

```
［名字］的表演：［体格与姿态——身体是他的传记］。［心理引擎一句——解释这副身体的内在驱动］。
声音行为：［音高音色、口音、语速与方式、情绪下声音怎么变——与声音圣经的音色锁一致］。
习惯与触发：［标志性习惯 + 何时出现］；［压力习惯 + 触发］；［掩饰行为——用什么藏住感受］；［面具，以及让它碎掉的确切条件］。
眼神：［眼睛对他人的常驻任务、眨眼质感与频率、扫视方式、眼先于头］。
步态：［起一个名字的步态 + 重心、节奏、落脚、上身与手臂、头部］。
但是，当［情绪触发］时，［姿态、步态、面孔如何转变］。
［可选：唯一一个会让他的脸真正柔软下来的人或物］。
```

规则：每个习惯都要有触发（`[习惯] + [何时/为何]`）；至少一个"但是，当……"的裂缝条款；不写服装、镜头、颜色、年龄。

示例：
> 周叙的表演：肩膀常年微微前扣，像一直在柜台后面低头核账的人，右手食指第二节有一层笔茧。他害怕被需要，因为被需要就要承担。声音行为：中低音，语速偏慢，句尾习惯性往下落；被逼问时会突然变短，只剩两三个字。习惯与触发：聊无关的事时用指腹来回抹书脊上的灰；被看穿时把眼镜往上推一下；掩饰行为是给自己找一件手上的活——整理、擦拭、对账。他的面具是礼貌的平静，当对方提起"那年冬天"时会碎。眼神：习惯看对方的手而不是眼睛，偶尔抬眼确认一下又落回去；眨眼慢。步态："柜台步"，小步、贴着书架走、从不走房间正中。但是，当她转身要走时，他会向前半步又停住，手悬在半空。唯一让他脸软下来的是那只店里的老猫。

## B. 本场改写（每场每条生成一段，交给编译师进【表演】段）

1. **只写本条在场的角色。**
2. **保留常量**：身份、声音行为、标志习惯、眼神方式、情绪主线。
3. **按本场重新表达**：选择、强调、修改或放下具体行为，适配姿势（坐/站/跑/躲）、动作、节拍、情绪、时段。
4. **转化，不删除**：坐着不能踱步的人，那股劲转进手指敲击、膝盖抖动、撕纸。
5. **一段连续文字**，不列清单。
6. **正文写"名字 + 一个可见标记"**，不写 @标签。

每个角色本场块包含：
```
此刻要什么（动词，对着某个人）｜在藏什么｜主导身体节奏｜本拍可见习惯｜本段内怎么变｜眼神任务｜手上在忙什么｜三轴（压力 / 幅度 / 控制）
```

**表演三轴**（2026-11-07，来自用户资料库的微表情 skill）：每个关键镜头打三个分，各 1–5。
- **内在压力**：心里的情绪有多大；
- **外在幅度**：脸和身体放出来多少；
- **自我控制**：他在多用力地压住。

压力减幅度，就是**微表情的空间**：差得越多，泄漏越细，越像真人。规则：
- 控制 ≥ 4 且压力 ≥ 4，必须写出**泄漏**在哪里（下眼睑一跳、喉结滚一下、手停在半空），否则模型会演成面瘫；
- 幅度大于压力，就是演过了，会像表情包；
- 一段之内可以变，写成"压力 3 → 5 → 2"。

数据里写成镜头的 `acting: {pressure, amplitude, control, leak}`（docs/19），`leak` 会写进提示词这一镜的动作；校验器提醒上面两条。词表和情绪变体见本目录 `表演词表.md`。

## C. 情绪的时间设计

- **反应链**：刺激 → 理解停顿 → 不自主的第一反应 → 选择后的反应 → 余波 → 下一拍。每拍 1–3 个可见线索，一次转变 2–4 个。
- **眼泪**：呼吸变 → 眼眶湿 → 眨眼节奏变 → 指定的晚拍才落一滴；写明"泪水不得提前出现"。
- **笑**：从压抑或触发开始，结束后保留呼吸和肩膀的余震。
- **怒**：先是身体的收紧（咬肌、下颌线、呼吸变浅），不是先吼。
- **静态镜头微生命**：每 1–2 秒一个微事件；分相眨眼"慢眨→快双眨→用力重置眨"；静止写成"绷住的张力"。
- **群体反应是波浪**：一个先懂，一个晚半拍，一个没懂；不要整齐划一。
- **威胁时刻全员定格**：持续的微动 → 关键威胁时全部停住，对比就是张力。
- **震惊只需要一瞬**，好看的是后面几秒的消化。**嘴还在笑，眼已经冷了**。越想保持笑容，细小的冻结和手上的动作越会露馅。闭眼、叹气、再睁眼，可以做气场反转的开关。
- **笼统的情绪先拆成变体**再写（"惊讶"至少分四种，见 `表演词表.md`）；**书写顺序**按通道：眼神 → 眼睑 → 眉间 → 嘴角 → 下颌 → 呼吸 → 姿态 → 声音。
- **四问**（每个表情动作都要答得上）：哪里动、往哪动、多大、被什么触发。答不上的就是情绪标签，不是表演。
- **台词就是表情的时间轴**：表情变化绑在具体的字上——台词前（被什么触发）→ 触发词（哪个字上变）→ 说的过程中（强调在哪个字）→ 停顿（换气、吞咽、视线下落）→ 说完之后（句后停在什么状态）。不写"说这句话时很难过"。
- **起、到顶、收**：情绪有起点、顶点、回落；第一帧不到顶，全镜不保持同一个表情；眼泪、脸红、大笑只在触发之后出现。
- **一拍一个主载体**：这一拍情绪落在眼睛、呼吸、手还是行动上，选一个主的、最多一个辅助，不让所有反应同时发生。
- **结束残留**：每镜写清结束时情绪停在哪里（手停在半空、呼吸还没平、视线没收回来），下一镜从这里接，不重新开始。
- **摄影机跟着情绪分阶段变**：一镜之内情绪变了，机器性格也跟着变，并绑定编号的表演拍（①②③），交摄影指导（crew/05 第 2 节）。

## D. 对白戏中的身体（与台词对白导演协作）

话轮、台词时间、停顿落位、口型约束归**台词对白导演**（`crew/23-dialogue-director`）；我接收他的台词时间表，负责每句台词期间说话人与听者的身体：
- **反应先于台词结束**：听者在句子中途已经明白，脸先回答。真人数据：对方句末前 0.2–0.4 秒脸和头就开始动；点头落在对方的断句处；说话的人约五分之一时间看别处，听的人基本看着对方；专心听时眨眼少（每分钟 9–17 次），说话时 2–3 秒眨一次；笑慢慢起、一秒左右就收（`真人对话数据.md` 第一节）。
- **写看得见的，不写情绪词**：acting.leak 和表演块从 `真人对话数据.md` 第二节"内心 → 看得见的表现"里挑两三个（尴尬 = 笑着移开视线 + 摸耳朵；怀疑 = 轻皱眉 + 歪头 + 摸下巴 + 眨眼变多）。只写"紧张""尴尬"，校验器会提醒。
- 每句台词配：说话人的身体动作 + 听者的同步反馈（视线、呼吸、手上的事停没停）。
- 精简模式下我兼任台词对白导演，按 `crew/23-dialogue-director/SKILL.md` 产出台词时间表。
- **唇部防崩**：情绪交给眉心、下眼睑、鼻翼、咬肌、下颌线、喉结；嘴"自然闭合、唇形放松"；不说话的人写"双唇自然闭合，安静地听"。
- **持道具对白**：视线落点与道具指向绑定到同一个空间锚点；道具放下/举起是情绪节拍（卸下防备/重新武装）。

## E. 审核（分镜与提示词的表演段）

- [ ] 每个在场角色有目标（动词）和隐藏
- [ ] 情绪全部是可见行为，无形容词标签
- [ ] 眼睛有任务、有眨眼设计
- [ ] 手上有事；最强一拍是否是"停下手上的事"或"听的那张脸"
- [ ] 泪/笑/怒有累积过程，时机正确
- [ ] 与表演母本常量不矛盾
- [ ] 无唇部压缩词、无年龄词
- [ ] 对白戏每句台词都有说话人身体与听者反馈（与台词时间表对齐）

输出 PASS/FAIL + 定位修改意见。

## 顶级标准（docs/20）

本岗位的产出先过 `docs/20-顶级标准.md`：第一节（不做等救主式电子垃圾）、第四节（每条视听丰富度预算，含"张力：不要四平八稳"），再过下面这几条。交出去之前问自己一句：这一步做到顶级影视团队的水平了吗？没有就改，不等别人指出来。

- 每场戏写"表面在做什么、心里在想什么、哪一刻露出来"。
- 表演靠动作和眼神，不靠表情；一处克制的小动作胜过一次哭喊。
- AI 翻译：对白镜头只给一个小动作并写明第几秒；情绪写成可见的身体动作，不写"他很悲伤"。
