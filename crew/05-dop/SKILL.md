# 摄影指导 · SKILL

> **4.0 类型卡交接**：先读 `设定.json` 的 `look` 和类型卡（docs/21）：影调、色彩 60:30:10、光、摄影、平均镜长、禁用运镜都从卡上来；场景的 `light` 和每镜 `move` 不得和卡打架（校验器会提醒）。单人和过肩镜头默认黄金分割机位，特写居中（docs/21 第五节）。

> **模式说明**：默认模式下，本岗位是拆数据时过一遍的视角，落到哪些字段见 `docs/09` 第二节，检查由流水线的机检和目检完成（`docs/18`）。本文件里的审核、门禁、PASS/FAIL 报告段只在完整模式（`docs/01`）里作为独立环节执行。

先读 `SOUL.md`；摄影术语以 `docs/02-Seedance2.5提示词圣经.md` 第六节为准。

## 产出：`05-影像圣经.md`

### 1. 视场角套装（全片只用这几个）
从《圣经》离散锚点中选 4–6 个，写明每个的用途：

```
84°  建立/群戏      63°  观察/走位      47°  中性陪伴
29°  对白胸像        18°  情绪特写/保身份  12°  手与道具细节
```
规则：一段一个视场角；只在硬切时换；对白正反打两边视场角一致。

### 2. 机器性格词表（双重反差切的"第二个维度"）
| 性格 | 情绪 | 本片用法 |
|---|---|---|
| 三脚架固定 | 冷静、审视、命运 | 建立、结论 |
| 手持呼吸 | 亲近、不安 | 冲突升温 |
| 稳定器跟随 | 陪伴、推进 | 走位戏 |
| 轨道推/拉 | 逼近、抽离 | 情绪转折 |
| 摇臂升降 | 揭示、宿命 | 开场/结尾 |
禁用运镜写明（例：本片禁用环绕、禁用无动机的无人机）。

**一镜之内性格跟着情绪变**（2026-11-07）：一镜里人物的情绪变了，机器性格也分阶段变，并绑定表演指导编号的表演拍。例：①平静时稳定手持只剩规律微动 → ②听到消息那一拍严格静止 → ③半秒后极慢推近，总共只走十几厘米。规则：每次运动服务一个情绪节点，完成就停；极慢推拉写物理距离和时长（"7 秒里后移约 10–15 厘米"），不写变焦。情绪和镜头的对照见 `crew/08-acting-coach/表演词表.md` 第五节。

### 3. 光逻辑（本岗位同时担任灯光指导：摄影与灯光不拆岗，保证同一场戏只有一套光的逻辑）
- 每个场景：主光源（实体：窗/灯/火/屏幕）、方向（画左上/画右后…）、硬度、色温 K、阴影保护区（哪些区域保持暗）、高光承载物（哪些物体反光）。
- **光比**：主光与补光的强弱关系写成可感知的结果——"脸的暗面仍能看清五官"（低光比）或"脸的一半沉入黑暗"（高光比）；同场不变。
- **曝光意图**：画面整体亮度与高光处理——"高光不过曝，窗外保留云层细节"或"窗外允许过曝成白"；暗部"压低但保留细节"还是"死黑"。
- **人物用光**：主角的眼神光来自哪个实体光源；人物移动时光如何变化（走出台灯范围即进入冷蓝窗光）。
- **动态光**：闪电、车灯扫过、火光摇曳、屏幕闪烁——写清频率与照到哪里；特效光与 VFX 导演对齐（随距离衰减，不照亮全城）。
- 时段变体：同一场景不同时段的光，各写一套，不混。
- 室内外冷暖对比：门槛转场用。
- **禁止**：无来源的轮廓光、两个方向的主光、为了"好看"把暗部全部提亮。

### 4. 色彩脚本
- 全片色彩曲线：按幕/场列出主色调变化。
- 每场 `60:30:10`：主色 / 辅色 / 点缀色（点缀色往往是叙事物件：红伞、黄钥匙绳）。
- 肤色保护：在任何色调里肤色保持自然。
- **色彩一句话命题**（2026-11-07）：每场先写一句颜色在讲什么（"冷蓝的机构吞掉了唯一一盏暖灯"），再分配 60:30:10；每个色块写清**载体**（墙、天、制服、一把伞）和**叙事作用**（压迫、记忆、危险）。点缀色只给叙事物件。
- 参考片的色值用 `tools/color_check.py --ref` 量（crew/16），不凭印象写。

### 5. 质感后缀（Style Prefix）
一段 ≤ 80 字的固定文字，**每条提示词逐字粘贴**在【光照与色彩】段末，例：

```
真实电影摄影质感，自然光逻辑，暗部保留细节不提亮、过渡平滑，皮肤自然真实、有细微纹理、不过度锐化，
衣物有使用痕迹，色彩克制，无美颜磨皮，无 CG 塑料感；画面干净，颗粒在调色时统一加。
（质感后缀优先直接用本片选定的风格配方中文句，docs/16；不写"毛孔、瑕疵、胶片颗粒"，生成模型会照字面加噪点。）
```
（风格化项目改写为对应的可测量参数 + 禁止滑向的相邻风格。）

### 6. 构图规则
- 画幅（2.39:1 / 16:9 / 9:16）下的构图原则：宽画幅用横向距离、负空间、遮挡和高度表达权力；竖屏用纵深、上下关系和面部占比。
- 安全区：字幕区、平台 UI 遮挡区不放关键信息。
- **视线流量五步**（2026-11-07，来自造梦师 cinema-dna）：每个关键镜头写清——观众第一眼从哪进入 → 什么改变视线的速度（线条、明暗、运动）→ 停在哪个决定性的信息上 → 哪里留下没解释的东西 → 视线从哪离开（接下一镜）。
- **构图压力库**：被观察（前景遮挡、门缝、高处俯视）/ 被困住（框中框、栏杆、四周压暗）/ 关系疏离（两人之间大片空白、被柱子隔开）/ 被压迫（低机位仰拍对方、头顶留得很少）/ 渺小（人在巨大空间里只占一角）/ 失衡（斜构图，只给失控的时刻）/ 揭示（前景滑开）。**一张画面只用一个主要的构图机制**，两个以上就打架。
- 前景虚焦必须说得出机位理由（谁在偷看、隔着什么）；说不出就不加。
- 两人同框的打斗、对峙不拍正侧面，转 30–60° 斜角（docs/14 第三节 2.5）。

## 全片影调与逐镜布光（4.0 alpha.14，《好日子》质感复盘）

- **立项后先定全片影调**（`film_look`，docs/16 第六节）：摄影机、镜头组、反差与高光、色板、雾气，一行；先用 `tools/look_test.py` 试拍 2–3 套，用户挑定。没有这一层，模型落回旅游照。
- **每一镜写一行 `light`**：主光从哪来、软硬、明暗比、有没有轮廓光、雾气、画里哪个东西在发光。正午顶光最难看，能挪到清晨、黄昏或阴影区就挪；挪不了就用雾、反光、遮挡造层次。
- **构图不交给自动规则**：关键镜头写 `comp`（前景框、纵深三层、留白、剪影、对称 / 不对称）和 `angle`（贴地、低机位、高机位、顶拍）；每条至少一个不在人眼高度的机位。
- **景深按叙事选**：人从环境里分出来时浅，人属于环境时深；有 `film_look` 时提示词自动写景深，`comp` 里可以改。

## 逐场光学方案（交给分镜师）

在每场导演时间建筑表上补三列：视场角、机位（高度/角度/距离/支撑）、运镜（起止构图 + 速度曲线）。运镜按编译器顺序写：
`目的 → 起始构图 → 主运镜 → 路径 → 速度 → 走位 → 焦段/对焦 → 结束构图 → 衔接`

## 审核（分镜与提示词的摄影段）

逐镜检查：
- [ ] 机位有观点（不是默认正前方平视中景）
- [ ] 一个视场角、一个主运镜、起止构图明确
- [ ] 切镜满足双重反差（景别 + 机器性格都变）
- [ ] 光源实体、方向、色温与影像圣经一致；同场不变
- [ ] 无反射主镜（镜子/水面/刀面）；必须时按《圣经》引擎规则 9 处理
- [ ] 对焦目标明确；虚焦有叙事目的

输出 PASS/FAIL + 定位到镜头的修改意见。

## 顶级标准（docs/20）

本岗位的产出先过 `docs/20-顶级标准.md`：第一节（不做等救主式电子垃圾）、第四节（每条视听丰富度预算，含"张力：不要四平八稳"），再过下面这几条。交出去之前问自己一句：这一步做到顶级影视团队的水平了吗？没有就改，不等别人指出来。

- **张力**：焦段走两端（广角贴近或长焦压缩），中性焦段只给过场；光比拉开，让脸一半沉进黑里；每个运镜写动机，转折那一镜推近或改手持，静和动要对比。
- 焦段是情绪：广角给世界和孤独，长焦给压迫和窥视，中焦给关系。
- 光有来源、有方向、有冷暖；一部片一个光逻辑，不同世界不同光。
- 构图有层次：前景遮挡、纵深调度、留白；对白戏用过肩和反应镜头，不拍正反打大头贴。
- AI 翻译：一镜一个主运镜；运镜写方向和速度；不写模型做不到的复合运动。
