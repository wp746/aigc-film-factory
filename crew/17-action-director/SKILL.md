# 武戏导演 · SKILL

> **模式说明**：默认模式下，本岗位是拆数据时过一遍的视角，落到哪些字段见 `docs/09` 第二节，检查由流水线的机检和目检完成（`docs/18`）。本文件里的审核、门禁、PASS/FAIL 报告段只在完整模式（`docs/01`）里作为独立环节执行。

先读 `SOUL.md`、`docs/03-30秒电影化叙事法.md` 结构 D、`打击与防守词表.md`（本目录）。只在分场表或导演阐述标注了动作场的场次启用。

> 2026-11-07（4.0 alpha.9）补：第 0 节体检，第 2、3、5 节细则，新增第 7 节镜头、第 8 节声音交接、第 9 节交付前五问。来源是用户资料库里的《列阵 · AI 打戏总导演》和 seedance-combat-prompt，只学方法；招式库里的 IP 内容不收。
>
> **优先级**：安全合规 > 剧本事实 > 物理真实与打击感 > 节奏情绪 > 镜头语法 > 特效风格 > 时长成本。**不许降级自救**：打不出重量，只能改机位、接触点、节奏或减特效，不许把"重击"偷偷写成"气浪掀飞"。

## 产出：`09-分镜/<场号>-动作设计.md`（交分镜师并入镜头卡）

### 0. 体检：该不该打、打几秒

先回答**逻辑五问**，答不上来的打戏不拍：
1. 为什么现在打？
2. 为什么不能用嘴解决？
3. 为什么打得过，或者为什么打不过？
4. 打完得到什么、失去什么？
5. 谁先动手，为什么？

再写一张**打斗基因卡**：
```
强度档：F1 冲突（推搡、一记耳光）/ F2 斗殴 / F3 格斗 / F4 战斗 / F5 规则级（超能力、巨物）
胜负手：最后决定输赢的那个东西是什么，必须在动作段前 1/3 埋下（一把刀、一块松动的地砖、一个旧伤）
身体母题：这场反复拍哪个部位（手 / 眼 / 喉 / 膝 / 背），开头、中段、结尾各一次
可武器化的环境：3 件
观众站位：观众站在谁那边、比谁知道得多
结论：打 / 改成一记耳光、一次摔门、一次掐脖（更狠、更省）
```

**没有动机、没有赌注、打完不改变关系的打戏，改成一个动作**。慢节奏的片子按"打得少、蓄得长、爆得狠"来：一场打斗只服务一次关系断裂；动手前 5 秒只有环境音，打完 3 秒只有呼吸。

### 1. 地形与站位
```
地形：狭长便利店过道，长约 12 米；画左是饮料冷柜（玻璃门），画右是零食货架；过道尽头是收银台。
站位（第一帧）：主角在过道中段面朝收银台；三名对手在收银台前呈半圆，最近一人距主角 2 米。
武器与可用物：收银台上的金属托盘；地面有洒出的水。
出口：主角身后的店门（画外后方）。
移动方向：全场动作沿过道从画左向画右推进，不反向。
```

### 2. 优势变化线
每个交锋单元一行：`单元 | 开始时谁占优 | 发生了什么 | 优势落在什么上 | 结束时谁占优 | 由什么驱动`。一条 30 秒生成最多 2–3 个单元。

- 一场动作段里，优势**至少轮转 3 次**（可以跨条）；
- 每次轮转要由**新信息、新资源或情绪爆点**驱动，不能只是"他突然变强了"；
- 胜负手在前 1/3 埋下，最后一次轮转用上它。

### 3. 逐击因果表
```
| 时间 | 招式名 + 意图 | 支撑 | 发力轨迹 | 接触/落空 | 受力反作用 | 可见结果 | 力量档 |
| 4–6s | 侧踢，逼退最近的对手 | 左脚撑地 | 右腿提膝侧踢 | 踢中胸口 | 对手双脚向后滑、撞上冷柜 | 冷柜玻璃门出现裂纹 | L3 |
```

五步因果的细则（每一步都可检查）：
- **支撑 / 发力**：发力六节点——蹬地 → 转胯（至少 30°）→ 腰 → 肩 → 肘 → 接触。至少写出蹬地和转胯。
- **接触**：写清打在哪、碰到什么。**接触点可见**：命中前后接触点都在画框里，不被手臂、背影或特效挡住；特效从接触点向外长，中心留空。
- **受力**：命中三张回执——接触点形变（衣服、皮肉、物件）、受力位移（头和躯干位移、脚步后退、呼吸被打断）、环境反应（尘、水、碎屑、家具移位、灯晃）。至少给两张。
- **质量与反作用**：轻的打重的，攻击者被反震（手腕发麻、退半步）。
- **击飞距离按力量档**：L1 轻击 5–15 厘米、L2 重拳 20–40 厘米、L3 重击 0.5–1.5 米、L4 击飞 2–4 米，而且必须落地、滚动卸力。
- **惯性**：衣摆、头发、血滴比身体晚一点停。
- **写法**：写"招式序列 + 落点 + 防守反馈"（"右摆拳打脸 → 左勾拳打下巴；防守方侧偏、下潜"），不写"快速连击""每秒 N 次"这类模型听不懂的频率词。
- 数据里写 `hit`（五步 + `weight` 力量档，docs/19）。

**十二条"软绵绵"禁则**：拳没碰到人就飞；打了没反应；站桩对轰只发光；小个子单手举起壮汉；被击飞落地还站着；空中定格摆姿势；脚不着力；慢镜三秒只看衣摆；特效糊住接触点；攻击者没有反作用；伤和损坏断了账；打完脸干净、衣服整齐。

### 4. 损坏累积账
每个人、每件东西的状态随时间累积：伤、喘、衣服破损、地面碎片、倒地者。下一条生成从这里继承（交场记）。账本加一列**"下一场必须带出"**：第几场、什么动作受限（右手握不住杯子、走路拖左腿）。

**越打越凶**：速度、力道、攻击方式三条线一起往上走；命中部位从躯干、手臂到肋腹，再到下巴、喉咙；环境反馈分五级——擦痕 → 裂纹 → 碎屑 → 碎裂塌陷 → 深坑；被击反应分部位（打脸头后仰、打腹弓成虾、打下盘跪地）。

### 5. 节奏
起势（地形交代 ≥2 秒）→ 试探 → 交手单元（3–5 连击）→ 顿一下 → 失衡 → 反转 → 爆发 → 终结 → 余波（≥3 秒）。冲击插入镜可以 0.3–1.5 秒。

- **五个速度档**：静 / 慢 / 常速 / 快 / 极速。同一档最多连续两镜，每三镜换一次档（数据里写 `speed`，校验器提醒）。
- **慢镜不超过动作段的 12%**，而且只给信息帧——接触点、表情、道具；单次不超过 0.8 秒，写速度百分比。
- **每 6–8 秒一个 1.5–3 秒的呼吸镜**（喘息、对视、捡武器）。
- **最重的一击落在动作段的 75–90% 处**（`hit.weight` 最大的那一镜，校验器提醒）。
- **终结前的定格或极慢**只在前面有至少 1.5 秒高速段时才有用，否则就是无聊的停顿。
- 打斗中台词全场最多一句，落在静默点上；被打断的半句比说完更狠。

### 6. 拆条与控制手段
- 本场有重表演（对白、哭、复杂眼神）→ 表演部分拆到另一条生成。
- 动作编排复杂或要求精确 → 向资产主管申请：授权的动作参考视频（5–10 秒最稳），或请分镜师用 Blender 做白模粗模。
- 同框追踪 ≤3 人；其余对手写成"作为一个整体后退/涌上"。

### 7. 镜头
- **每镜一个任务**：建地理、证力量、证速度、证疼痛、证情绪、证招式、证环境，选一个；两个任务拆两镜。
- **三镜定地理**：全景（双方 + 两个参照物）→ 过肩或反打 → 一个空间障碍物的特写。
- **特写三连**：眼（意图）→ 手或武器（发力）→ 接触点（结果），每场至少三组。
- **命中给两镜**：接触点特写（不超过 0.6 秒）+ 受力方反应（0.4–1 秒）。重击（L3 以上）不放在一条的最后一镜，后面要有反应镜（校验器提醒）。
- **景别配动作幅度**：小动作（拳、掌、肘、格挡）配近景、中近景；大动作（腾空、旋转、扫腿、下劈）配全景、中景。小动作配全景信息就稀了，大动作只给近景就只看到半个人在扭。
- **景别不跳级**：近景转远景要经过中景（命中 → 被击退跟拉 → 撞墙全景）；远景转近景可以一步到（突进本身带速度）。全景直切特写全场最多两次；连续特写最多两个；每五镜至少一个全身。
- **两人同框不拍 90° 侧面**：中景以上两人全身同框时，机位和两人连线成 30–60° 斜角，不拍成横版格斗游戏（白模几何检查会列出来，docs/14 第三节）。近景、特写才可以拍正侧面。
- **运镜跟着攻击方向走**：速度感来自镜头配合攻击方向的移动，不是动作本身。写清跟随目标（`move.follow`："跟随双臂攻防交错的方向"）。不用 360° 环绕和螺旋上升；对峙蓄力最多半圈。
- 越轴只在攻守反转时，全场最多两次。

### 8. 声音交接（交声音导演、后期声音与混音师 crew/24）
在逐击因果表里标出每一下接触的时刻和力量档，后期按它对音：接触帧音效和画面同帧，挥动的风声提前 3–6 帧起，终结前 8–12 帧把声音抽空，力量档决定尾音长度。

### 9. 交付前五问
1. 每一下打在哪，观众看得见吗？
2. 打完他疼了吗？（用行为证明）
3. 有没有一处静默？
4. 最重的一击在第几秒？
5. 这场删掉，剧情崩不崩？

## 审核
审镜头卡和提示词【物理】【时间轴】：地形与方向清楚；每击五步完整、顺序正确（不能先飞后打）；优势落在具体东西上；损坏继承；没有出画再入画；没有用镜头乱晃掩盖动作。

## 顶级标准（docs/20）

本岗位的产出先过 `docs/20-顶级标准.md`：第一节（不做等救主式电子垃圾）、第四节（每条视听丰富度预算，含"张力：不要四平八稳"），再过下面这几条。交出去之前问自己一句：这一步做到顶级影视团队的水平了吗？没有就改，不等别人指出来。

- **落到数据**：每个动作镜头写 `hit` 五步（支撑、发力、接触、受力、结果），一镜只拍一击；动作词出现而没写会被校验器拦（docs/19）。
- 每一击有因果：支撑、发力、接触、受力、结果；优势在打斗中至少换一次手。
- 环境参与打斗；伤和损坏要累积。
- AI 翻译：高速多主体动作拆条，必要时用白模或动作参考视频，拆短条。
- **模型做不好的镜头挪到后期**：顿帧、0.3 秒的特写、一镜多个动作、五人围攻、铁管 / 绳 / 链 / 飘带这类柔性细长道具（容易穿模，docs/14 4.2）。后期补物理的做法见 crew/15。
