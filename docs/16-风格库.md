## 一、从 493 张里学到的口味（不论用哪个模型都按这个写）

1. **是电影剧照，不是"渲染图"**：介质约一半是近真人的电影级 CG，约三成是真实照片或胶片。**没有卡通，也没有"略带风格化的 3D 动画"。**
2. **光有来源、有方向**：逆光、侧光穿雾、窗光、灯笼光、雷光，基本都是暗调；平光只出现在刻意的荒诞喜剧里。
3. **双色调色**：暖琥珀 / 暖金对冷青 / 冷蓝，整体降饱和；或者单一主色加一点点缀色。
4. **空气感**：雾、尘、雨、粒子、体积光几乎每张都有；前景有遮挡，景深分层。
5. **镜头写清楚**：焦段、浅景深、机位，尺度反差（极小的人对极大的物）。
6. **人在环境里、在一个瞬间里**：人物图也像"某个故事时刻的剧照"。
7. **质感真实**：布有织纹，木有木纹，地上有水渍，皮肤自然、不磨皮；但出图时画面要干净，颗粒感留到后期统一加（见第二节）。
8. **写法**：英文自然语言，主体放最前，然后环境 → 光 → 介质 → 镜头；写看得见的东西，少写抽象形容词。

## 二、MJ 参数怎么翻成 Image 2.5 / Banana 的语言

| 样图里的 MJ 写法 | 翻成 |
|---|---|
| `--profile` / `--sref` 风格码 | 不能用。改写成它产生的效果：配色、光的来源和方向、介质、颗粒，也就是对应的风格配方 |
| `--raw` | "true-to-life photographic rendering, natural imperfect skin and materials, no beautification, no smoothing" |
| `--stylize` 50–150 | 写实措辞，强调真实材质、普通光线 |
| `--stylize` 500–1000 | "painterly concept-art grandeur, heightened color and light"（只在奇观大场面用） |
| `--hd`、`--ar 16:9` | 模型尺寸参数：Image 2.5 用 3840×2160，Banana 用 4K 16:9 |
| `--no xxx` | 改成肯定句，写画面里有什么（工厂规则：提示词里不写否定）；只保留 "No text, labels or watermarks" |
| `--chaos` | 不用；我们不靠抽卡碰运气 |
| 胶片颗粒、`Kodak Vision3 grain`、`halation`、"看得见毛孔和瑕疵" | **出图时一律不写。** MJ 把这些词渲染得很轻，Image 2.5 / Banana 会照字面加噪点，暗调场景最明显；"毛孔、瑕疵"会让皮肤像砂纸，过度锐化，人反而显假。改写成 "clean, noise-free image with smooth shadow gradients"、"natural realistic skin with subtle texture, not retouched, not over-sharpened"。要颗粒感就在剪辑调色时统一加 |

**两个模型的写法差别**
- **Image 2.5**：能吃长的结构化说明。把配方放在单独的 `STYLE:` 段，位置在内容和版式之后。三视图这类版式图里，配方只管介质、材质、光和调色：背景仍然是无缝底，但颜色按配方色调染；光改成配方主光色的柔和主光加一道轮廓光，不用影棚平光。
- **Banana 2**：一段自然描述。开头一句定风格（"A cinematic photoreal still in …"），接着写内容。可以上传本项目已经定稿的图当风格参考，写明"只学它的光色和质感，不学内容和构图"。
- **Seedance / 其他视频模型**：配方里的英文就是本片的**质感后缀**，逐字写进每条的"光与质感"段（中文提示词就把配方翻成中文，同样逐字复用）。

## 三·五、出图版和视频版（4.0 alpha.10）

配方的 `zh` / `en` 是从风格样图里提炼的，里面有些是**画面内容**，不是质感：R06、R15、R19 的"一个极小的人作尺度"，R14 的"身后雾里隐约有一个巨大的暗影"，R15 的"巨大的生物占画面三分之二"，R12 的"一个普通人在荒唐灾难旁"，R24 的"一个人很小，或半藏在画面边缘"。出风格样图时这些是对的；整句进了视频提示词，每一镜都会凭空多出人和东西（万相实拍出了巨大暗影）。

所以这几个配方另有 `video_zh` / `video_en`：只写光、色、质感和情绪。**视频提示词只用视频版**（`storyboard.py` 自动取），出图仍用原文。以后新加配方，凡是写了"一个人""一座""巨大的……占画面"这类画面内容的，同时写一份视频版。

## 四、在工厂流程里怎么用

1. **立项时选风格**：按片子的几个"世界"（比如本片的天庭 / 劫云 / 人间）加人物质感，各挑 2–3 张候选样图，用 `tools/mj_style.py <编号…> --sheet` 拼成对比图给用户选。选定后在立项书和《世界观与美术设定》里写明每个世界用哪个配方。
2. **写资产提示词**：每张资产图的 `STYLE` 段逐字套用所属世界的配方；人物三视图用"人物质感"配方，场景主图和宫格用所属世界的配方。
3. **出群像**：风格选定后，按世界各出一张群众演员群像（docs/17），和主角三视图一起给用户参考，群演的质感用同一个配方。
4. **先出 1 张试图**，对照样图看像不像；不像就改配方的措辞，改定的措辞全片复用。
5. **写视频提示词**：配方就是质感后缀，逐字复用；有 `video_zh` / `video_en` 的配方用视频版（三·五）。
6. **用户说"风格怪""不好看"时**，先回到样图库挑卡、换配方，不要自己堆形容词。

## 五、反例：《天劫外包》小雷第 1 版为什么"怪"

| 问题 | 原因 | 改法 |
|---|---|---|
| 塑料感，像游戏 NPC 或皮克斯真人化 | 介质写成 "3D animated feature film look, slightly stylized"，卡在动画和写实之间 | 用 R04 这类近真人电影人像配方 |
| 没有情绪，像证件照 | 三视图只有影棚平光和浅灰底 | 版式保留，光和调色按配方来 |
| 孩子气 | 只写了"瘦小"，没写年龄和骨相 | 写实际年龄、骨相、皮肤状态（"early twenties, gaunt cheeks, tired eyes"） |

## 六、全片影调 film_look（4.0 alpha.14，《好日子》质感复盘）

《好日子》资产一出来就"平平无奇"：风格配方只管配色和光，提示词里没有任何摄影机、镜头、调色的锚点（被当成"堆词"删光了），模型就落回它最熟悉的样子——旅游照、HDR、处处清楚。复盘要点见 CHANGELOG alpha.14（《好日子》是测试片，已删除）。

**做法**：立项后、批量出图之前，定一条全片影调，写进 `设定.json` 的 `film_look`：

```json
"film_look": {"zh": "中文一行", "en": "English one line", "lens_zh": "变形宽银幕"}
```

- **写什么**：摄影机（如 ARRI Alexa 65）、镜头组（变形宽银幕 / 老式球面）、画面比例的感觉、明暗反差和高光怎么滚降、全片色板、雾气和光的质地、焦外的样子。一行写完。
- **不写什么**：导演名、片名、HEX 色值；8K、UE5、masterpiece；颗粒和"毛孔、瑕疵"（出图模型照字面加噪点，颗粒后期统一加）；几套胶片型号同时写。
- **进哪里**：场景主图、宫格、群像、首帧图的 STYLE 段，每一条视频提示词的"质感"段（"影调：……"），逐字一样。人物三视图、道具图、巨物设定图**不加**，保持中性参考。
- **镜头写法跟着变**：有 `film_look` 时，视频提示词的镜头写成"35mm 变形宽银幕镜头（视场约 63°），机位腰高仰拍，浅景深，背景虚化"，不再只写"63°"；可选字段 `light`（这一镜的布光）、`comp`（构图手法）、`angle`（ground / low / high / overhead，白模机位跟着变）见 docs/19。
- **成像逻辑：摄影机预设**（`config/camera_presets.json`，用户 2026-11-09）：机身决定宽容度和色彩科学，镜头组决定焦外、耀光和锐度，胶片决定颗粒和高光，"补充效果"是看得见的后果。模型对这些器材组合有很强的先验，比写"电影感"准得多。三层：`film_look.camera` 全片一组 → `worlds.<世界>.camera` 某个世界换一组（夜景霓虹换 C03）→ 镜头的 `camera` 单独换一镜（灯串下的人像换 C04）。镜头写成"Cooke S4/i 35mm（视场约 63°）"；单镜换了预设，提示词写"这一镜换成 RED V-RAPTOR……"并带上它的成像效果。选了预设，`film_look` 的 zh / en 就只写调色、色板、雾气和光，不再写机身（会打架，校验器提醒）。

  | 预设 | 组合 | 用在 |
  |---|---|---|
  | C01 胶片质感 | ARRICAM LT + Cooke S4/i 50mm + Kodak VISION3 500T | 剧情、年代、人物戏 |
  | C02 自然清晰的人物 | Sony VENICE 2 + ZEISS Supreme Prime 50mm | 现代都市、对话、广告 |
  | C03 夜景与霓虹 | RED V-RAPTOR + Laowa Proteus 35mm 2x Blue | 夜景、霓虹、科幻都市 |
  | C04 灯串下的人像近景 | RED V-RAPTOR + Laowa Argus 35mm T1 | 夜间人像、烛光、情感戏 |
  | C05 宽银幕史诗 | ARRI ALEXA 65 + Panavision Ultra Panatar | 史诗、巨物、大场面 |
  | C06 暗调变形恐怖 | ARRI ALEXA 35 + Atlas Orion Anamorphic + VISION3 250D | 恐怖、悬疑、民俗恐怖 |
  | C07 16 毫米手持纪实 | ARRIFLEX 416 + ZEISS Ultra 16 + VISION3 500T | 纪实、回忆、伪纪录片 |
  | C08 年代胶片日景 | Panavision Millennium XL2 + C-Series Anamorphic + VISION2 200T | 年代、西部、民俗日景 |

- **缺陷质感**：颗粒、光晕、暗角、焦外畸变写在预设的补充效果里，视频提示词带全；场景图用 `stills_en`（默认不带颗粒，Image 2.5 会照字面画成噪点）。试拍时 `look_test` 的选项写 `"grain_in_stills": true` 可以验证带颗粒出图的效果，验证过再放开。
- **先试拍再定**：`设定.json` 写 `look_test`（2–3 套候选 + 3–4 个关键时刻），`python3 -I tools/look_test.py <项目>` 生成出图清单，`tools/image_gen.py` 出图（约 0.036 美元一张），`look_test.py <项目> --sheet` 拼对比图，用户挑一套写成 `film_look`。
- 校验器：写了 `film_look` 缺中文或英文就报错；立了项却没有 `film_look` 提醒。没写 `film_look` 的老项目产物不变。
