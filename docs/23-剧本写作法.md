## 一、内核：观众到底为什么看下去

### 1. 情绪承诺

每部片立项时写一句：**观众看的是什么感**。例如"爽""揪心""笑着笑着哭了""毛骨悚然""越看越不对劲"。全片每一条都要往这个感觉上加码，最后兑现。写进 `设定.json` 的 `core.promise`。

爆款卖的是**情绪代偿**：先把观众日常受的委屈**放大、具体化**，再一次性**加倍还回去**。这一套机制本身没有错，错在"还回去"的方式是等救主。我们保留"委屈具体化"和"翻转幅度大"，把"还回去"换成主角自己的选择和代价。

### 2. 大众母题（docs/11 货架 E）

用户的口味库（docs/11）偏高概念黑色幽默，**主流母题同样是口味的一部分**，只要主角是主动改写它的人。

| 母题 | 观众的欲望 | 爆款的做法（不学） | 我们的改写（学） |
|---|---|---|---|
| 重来一次（重生、循环、穿越） | 后悔可以重来 | 重生后开挂，仇人自动倒霉 | 重来要付代价：这次救了 A，就保不住 B；或者每重来一次就忘掉一件事 |
| 被看轻的人（隐藏身份、反差） | 被看见 | 一个电话叫来大佬，众人跪下 | 他的本事是**一个具体的手艺或规矩**，在关键时刻自己选择亮出来，亮出来就回不去原来的生活 |
| 被偷走的人生（真假千金、偷换） | 拿回本属于我的 | 认亲揭晓，豪门接回 | 她拿回来的方式是设局，而拿回来的东西已经不是她想要的样子 |
| 家里的坏人（渣男、恶婆婆、背叛） | 把委屈外化成能打的人 | 反派降智，被路人打脸 | 反派有自己的正当性（他也对），主角赢的是一场"规则之内"的仗 |
| 守护（萌宝、幼兽、弱者） | 被需要 | 孩子是工具，负责喊爹地 | 被守护的一方也有欲望，最后反过来救了守护者一次 |
| 规则恐惧（门规、禁忌、怪谈） | 在可控的危险里找刺激 | 规则随剧情乱改 | 规则在第一条立死，结尾**恰好按规则**反杀或被反杀 |
| 甜到顶点再翻脸（虐恋） | 被爱、被背叛 | 误会靠不说话撑十集 | 翻脸来自双方都对的立场，不来自巧合的误会 |

### 3. 委屈要具体，欲望一句话说清

- 不是"婆家对她不好"，是"想要二十块钱坐地铁，婆婆把零钱甩在地上"。
- 不是"他被看不起"，是"他在路边摊吃的那碗面被打翻了"。
- 欲望一句话能说清，最好落在**一个东西、一个数字或一个期限**上。

### 4. 两难写成双输

主角的关键选择必须是：**做 A 失去 X，不做 A 失去 Y**。只要主角有一条不付代价的出路，这个两难就是假的。写进 `core.dilemma`。

### 5. 设定即情感

世界观里最关键的那个物件，同时也是人物关系的信物。《流浪地球》里，木星既是引力危机，也是父亲对儿子的约定："等你不用望远镜就能看到木星的时候，爸爸就回来了。"设计世界时先问：**哪一个设定物件能同时承载一段关系？**

## 二、人物

### 1. 人物小传（每个有名字的角色一份，写在 `02-世界观与美术设定.md`）

```
姓名｜一句话定位（职能 + 处境）
性格三层：表层（别人看到的）/ 深层（真实的驱动）/ 阴影（最怕被看穿的）
反差：表面 X，实则 Y（只选一条，不要堆）
欲望（想要的具体东西）/ 需要（真正缺的）
压力写成数字：钱、时间、人、权（"月供一万二，卡里八千，还有七天"）
资源与制约：手里握着什么（半块虎符、一段录音、一个秘密）/ 被什么卡住（把柄、恩义、规矩）
语言指纹：高频词、绝不说的词、句子长短、口头禅两句样例
关系：和每个主要角色的渊源、制约、立场、变化
功能（配角）：施压者 / 共情者 / 对立者（有自己的道理）/ 见证者（伏笔载体）
弧光：开头做不到什么 → 结尾做到了什么 → 付了什么代价
结局：写到结局，配角也写
```

外形、剪影、服装磨损交给角色造型师（crew/07），不在这里重复。

### 2. 第一个动作就是人设

主角第一次出场，**用一个动作立住他是谁**，最好和观众以为的相反。不要用台词或旁白介绍。

- 路边摊的面被打翻，他只说："你，砸了我的饭。"对方问"怎么？"，他只回一个字："赔！"三个字立住冷、狠、讲自己的规矩。
- 恶毒女配一边温柔地给庶妹梳头，一边用簪子划伤她的脸——开场就让观众知道她不是好人，也知道她手稳。
- 外卖员用一个网球打开豪车门锁，被保安撞见，笑着说自己兼职代驾——动作立聪明，台词立油滑。

### 3. 用第三人的嘴交代关系

身份和关系不靠自我介绍和旁白，靠**另一个人在冲突里说出来**。比如岳母当着外人抱怨"送来的却是个傻子"，一句话交代了入赘、残疾和家里的态度。

### 4. 忍要有主动的理由

主角被欺负时不还手，要给一个**他自己选的理由**：答应过谁不暴露本事、对方手里有人质、还手就会输掉更大的东西。没理由的忍就是窝囊，观众会弃剧。

### 5. 反派有自己的正当性

爆款的反派只负责羞辱，这一条反着学。反派要有一个"他也对"的理由，冲突才有重量。检验：让反派写一段自辩，能说服三成观众吗？

### 6. 有名字的人都写到结局

每个有名字的角色，在剧本里都要有一个收尾的状态，哪怕只是一个镜头。

---

### 7. 心理活动写成动作，不写情绪词

不写"她很悲伤""他痛苦极了""他心里一沉"。剧本里的心理活动只用看得见、听得见的东西写：手上的事停住或做不完、视线落在哪里、呼吸卡在哪一拍、哪个字说不出来、身体往哪边让。写之前问四问：哪里动、往哪动、多大、被什么触发。词表见 `crew/08-acting-coach/真人对话数据.md` 第二节和 `表演词表.md`；拆进分镜后，动作、节拍、表演泄漏、台词语气只写情绪词，校验器直接报错。

## 三、冲突与反转

### 1. 威胁阶梯

爆款的"打脸阶梯"改造成**威胁阶梯**：
- 每一级的对手比上一级更大（小弟 → 大哥 → 大哥背后的人）；
- **每一级都是对手自己抬高赌注**（"你活不过今晚""整个城没人护得住你"），所以摔得更重；
- 主角靠**自己的选择和代价**过关，不靠打电话叫人。

### 2. 信息差的三种用法

| 用法 | 效果 | 什么时候用 |
|---|---|---|
| 观众知道、主角不知道 | 揪心（悬念） | **优先用**。监视器里的偷拍、侍卫其实是皇帝的人 |
| 观众知道、反派不知道 | 爽 | 少用，用就要让反派的无知有代价 |
| 双方知道、旁人不知道 | 张力、喜剧 | 灵魂互换、两人都不知道对方就是自己的配偶 |

每条在 `tension` 里写清用的是哪一种。

### 3. 设局 → 拆局 → 反将

- 每一步抖出一条硬信息；
- 翻盘的证物必须是**前面埋过的伏笔**，不许巧合、不许天降；
- 埋设和回收写进 `设定.json` 的 `foreshadow`，校验器会查"回收在埋设之前"。

### 4. "以为……却不知……"计谋库

不依赖救主的信息差反转，都可以写成一句"A 以为……，却不知……"：

反间、计中计、关门捉贼、偷梁换柱、狐假虎威、反客为主、以毒攻毒、连环计、借题发挥、顺水推舟、请君入瓮、调虎离山。

剔除"隐藏大佬掉马""众人跪舔"两类。

### 5. 施力 × 受力

反转越狠，前面的施力要越足，主角承受的损失要越真。检验：把反转前一条删掉，反转还那么爽吗？还那么爽，说明前面没施够力。

### 6. 同一时间，两种待遇

把冲突放在**同一时刻的对比**里：
- 她在产房快死了，出来撞见丈夫陪别人产检；
- 火场里他抱走装病的人，把妻儿留在火里。

对比比单独的伤害狠十倍，而且一个镜头就能拍出来。

### 7. 小冲突加赌注

任何文戏先问：**赌的是什么，输了怎样**。一个排座位的小争执，加上"我们赢了就自己排座位，输了站着上一星期的课"，就变成了观众要看结果的比赛。

### 8. 结尾三件事

1. **代价呈现**：主角赢了，也失去了什么，镜头给它；
2. **关系新平衡**：不全员和解，关系变成了一种新的、不完美的样子；
3. **意象照应**：开场出现过的物件、台词或动作，在结尾换了意义再出现一次。

## 四、对白

### 1. 台词七维（写完逐场过一遍）

| 维度 | 问题 | 测试 |
|---|---|---|
| 1 辨识度 | 盖住名字，认得出是谁在说吗？ | **遮名测试**：主要角色八成以上台词遮名可辨 |
| 2 潜台词 | 说的和想的一样吗？ | 关键戏至少一处相反，用动作透出来 |
| 3 冲突推进 | 这句说完，有没有一样东西变了（信息、权力、关系、情绪、风险）？ | 连续 3 句没有变化就删 |
| 4 类型语感 | 古装、科幻、职场的话味对不对？ | 没有串戏词；职业说职业话 |
| 5 信息效率 | 一句只抛一个信息吗？ | **删字测试**：删掉一半还成立就删 |
| 6 节奏 | 长短交错吗？说得出口吗？ | 连续 3 句字数相近就改；单句不超过 20 字 |
| 7 记忆点 | 有没有一句让人想转发的？ | 每场最多一句，只属于这个人 |

再加一个**替换测试**：这句能不能换成一个动作或道具？能换就换。

### 2. 有目的

每句台词都在做一件事：争取、回避、试探、逼迫、示好、羞辱、拖延、威胁、重新定义关系。写不出它在做什么，就删。

### 3. 槽点：一句话完成地位翻转

- **权力倒转句**：长公主捏起侍卫的下巴，"伤好之后，来我房内伺候。"一句话立住欲望和权力。
- **一句调情就是一次谋杀的前奏**："大帅，你看这枪，配我吗？"——下一秒枪口对准他。
- **称呼打脸**：重生后嫁给渣男的小叔叔，让渣男喊她"小婶婶"。一个称呼完成地位翻转，零成本，对 AI 视频尤其友好（不需要复杂动作）。
- **把对方的话原样还回去**：开头骂人的狠话，结尾一字不差送给对方（docs/11 #004 台词回旋镖）。

### 4. 梗：每场最多一句"只属于他"的狠话

我们禁的是 **AI 腔口号**：排比三连、"不是……而是……"、总结人生的感悟句、谁说都一样的漂亮话。

我们要的是**人物金句**：短、狠、换个人说就不对。例："你，砸了我的饭。""第七条，不可抗力。不赔。"检验：把这句给另一个角色说，还成立吗？成立就不是他的金句。每场最多一句。

### 5. 潜台词

说的和想的相反，**用动作和道具透出来**，不用心声念出来。爆款几乎每场都有 OS 心声，这是它最大的局限。

- 外公接过地下城的铭牌，只说一句"醒着的时候，就多给孩子打打电话。不然，很快，他就会忘了你……"——不说反对，反对全在里面。
- 嘴上说"没事"，手里的杯子没放下，停在半空。

### 6. 台词钩子

一条（或一集）可以停在一句台词上，这句台词要是：
- **半句话**："他是……"
- **一句反常的陈述**："你老公身上趴了个人。"
- **一句把局面翻过来的话**："船刚才已经全凿沉了。"

### 7. 不许写的

- 灌输式："你忘了吗，三年前……""你是我爸，你怎么能……"（明知故说）；
- 自报家门："我，某某集团总裁某某某"；
- 旁白替人说心理；
- 把潜台词说成台词："我知道你一直在躲我，因为你害怕。"；
- 霸总羞耻句、网文万能句。

### 8. 和台词五招的关系

crew/23 的台词五招（先动作后台词、标点写呼吸、回问一个词、难出口变小声、决定性小动作）管的是**说得像人**；本节七维管的是**写得好**。两样都要过。

## 五、节奏与情绪曲线

### 1. 3-7-30

- 0–3 秒：视听钩（一个反常的画面、声音或一句话）；
- 3–7 秒：第一个悬念或反差；
- 7–30 秒：第一次反转。

单片的第一条、剧集每一集的第一条都按这个写。

### 2. 开场五类（前 3 秒）

| 类型 | 例子（只学方法） |
|---|---|
| 死亡或濒死现场 | 火场楼梯、刀已经捅进去 |
| 当众受辱 | 饭被打翻、众人议论她怎么死的 |
| 反常画面 | 纯黑里一束顶光，蟒袍玉带闭目横刀；前台少女咬掉一根手指 |
| 一条世界规则 | 机械音宣布"经济下调一亿倍"；"11 点之后必须关门" |
| 强者降临 | 机车停在别墅门口，黑衣人清场 |

**用"假的正常"揭示世界**是高级的变体：教室阳光明媚、齐读课文，一个动作之后阳光灭了——原来是 LED 屏，蝉鸣还在响。

### 3. 先压后放，压的终点是翻身点

- 情绪先压住，压到最低谷（死亡、被抛弃、全输），紧接着就是翻身点；
- **单片**：在全片约 1/4、1/2、3/4 处各放一次大的价值翻转（相当于短剧的付费点）；
- **剧集**：压抑不超过 3 集必须释放（docs/22）。

### 4. 慢必须有功能

慢镜、空镜、沉默、长停顿，至少承担下面一项，否则删：
1. 情绪在变；
2. 悬念在加深；
3. 关系在变（视线、距离、称呼、身体）；
4. 一条关键信息在释放；
5. 一个视觉记忆点（截图能当封面）；
6. 动作在蓄力（爆发之前的静）。

### 5. 五条节奏红线（踩一条就改）

1. 开场 3 秒只有风景、天气、慢走或背影，又没有悬念；
2. 连续两场是同一种情绪，没有新信息；
3. 长对白解释设定，却没有动作或关系变化；
4. 长空镜，观众不知道该看什么；
5. 留白结尾，却没有情绪回响，也没有回扣开头。

### 6. 功能标签

每一条（单片）或每一集（剧集）打一个功能标签，写进 `分镜.json` 的 `tag` 或 `季.json` 的 `tag`：

`铺垫` `推进` `压` `放` `反转` `揭示` `钩` `余韵`

连着三条一样的标签，校验器会提醒：节奏单调了。再加一列"信息点"（这一条交代了哪条新信息），看信息是不是均匀地投放。

### 7. 甜到顶点，当集翻脸

库里唯一有播放量数据的规律：《长公主在上》第 21 集播放 3930 万，前后几集只有 800–1100 万。这一集同时发生了三件事：两人刚刚在一起（甜到顶点）、身份被揭穿、当场翻脸。

用法：剧集的中段高光、单片的 3/4 处反转，可以把**亲密的顶点和背叛放进同一条**。翻脸要来自双方都对的立场，不来自巧合的误会。

### 8. 私人尺度硬切宇宙尺度

最小的场景直接切到最大的场景，中间不过渡：肝癌晚期的乡村老师说"时间不多了"，下一镜是舰队报告"目标编号……发现生命"。私人的死和文明的生死压在同一时刻。这是最接近《爱死机》的剪法，科幻、巨物、灾难片的高光可以这样设计。

## 六、集尾与条尾的钩子

### 1. 十二类钩子

| # | 类型 | 例子 |
|---|---|---|
| 1 | 生死悬停 | 刀举到最高点；车灯迎面 |
| 2 | 身份揭晓前一秒 | "大小姐，终于找到您了！" |
| 3 | 半句话 | "他是……" |
| 4 | 更大的对手进门 | "某某某到！" |
| 5 | 反常陈述 | "你老公身上趴了个人。" |
| 6 | 宣战 | "那些欠了我的人，噩梦开始了。" |
| 7 | 认知颠覆 | 镜子里不是自己的脸 |
| 8 | 亲密被打断 | 唇快碰上，门开了 |
| 9 | 喜剧定格 | 两人望着门，愣住 |
| 10 | 物证特写 | 学生证上的照片是他，名字却是别人 |
| 11 | 时间戳循环 | 每次死去，手机上都是 20:44 |
| 12 | 规则宣告 | 登记表上多了一个怪问题 |

### 2. 规则

- 集尾不能是"已解决"（"然后他们回去睡觉了"）；
- 同一类钩子不连用 3 次（剧集写 `hook_type`，校验器提醒）；
- **钩子落在一个动作上**（灯一灭、印落地、手松开）比喊一句台词高级；
- 不用擦边悬停，不用"等救主"悬停（"就在这时，一个声音响起……"然后靠别人解围）。

单片没有集尾，同样的技术用在**每一条的结尾**：每条结尾的价值翻转（`turn.to`）就是这一条的钩子。

## 七、剧集的结构（补 docs/22）

- **前 3 集决定生死**：《长公主在上》第 1 集到第 6 集播放量掉了 79%。前 3 集每集都要有一次大翻转。
- **起承转合按集数配比**：约 6% / 17% / 61% / 16%。"转"由 2–6 集一块的**事件块**组成，每块一个对手、一次翻转。
- **对手接力**：一个对手倒下，下一个接棒，越来越大（威胁阶梯在剧集里的样子）。
- **身份揭晓要排期**：哪一集揭什么，写进 `季圣经.md`（背影卡 `reveal_ep` 已支持）。
- **单元 + 主线**：每集一个独立的小案子，背后一条主线慢慢推进。
- 每 10 集至少 3 个**可讨论的话题点**（观众会在评论区吵的选择）。

## 八、高水准的写法（范本）

| 写法 | 范本（只学方法） |
|---|---|
| 设定和情感是同一个物件 | 《流浪地球》的木星；童年信物 |
| 用"假的正常"揭示世界 | LED 阳光熄灭，蝉鸣还在 |
| 用"没见过"定义世界 | "我没见过黑夜，我没见过星星，我没见过春天、秋天和冬天。"——用失去的东西写世界 |
| 尺度要有参照物 | "而你，是那巨大宫殿地板上的一个细菌"——先给人的尺度，再给宇宙的尺度 |
| 大事件压在一个具体的人身上 | 让一个小人物替观众经历灾难 |
| 私人尺度硬切宇宙尺度 | 乡村老师"时间不多了"→ 舰队报告 |
| 道具替观众看穿伪装 | 新炼成的扇子在师父袖子里震了一下——观众知道她女扮男装，师父起了疑 |
| 同一句台词前后对上 | 梦里"抓住你了"，现实里抓住真凶时又是一句"抓住你了" |
| 元叙事 | 女配能看见写好的命书，和"作者"对抗；墨字悬在半空 |
| 平行空间 | 父亲说"我没打过你"是真话——打人的是另一个空间的父亲 |

## 九、不学的（再说一遍）

| 爆款的做法 | 为什么不学 |
|---|---|
| 男主及时出现救场 | 等救主，内核闸门 F 一票否决 |
| 反派单一扁平、大喊大叫、不通情理 | 冲突没有重量 |
| 一个电话三分钟叫来大佬；用腿接子弹 | 规则一旦立下就不破，这是我们和短剧的分界 |
| 起因 10% / 羞辱 80% / 钩子 10%，释放留到下一集 | 单片没有下一集；每条都要有翻转 |
| 心声 OS 把潜台词全念出来 | 削弱表演和画面 |
| 性暴力、擦边、强迫当钩子 | 低级，违规 |
| 民族情绪、政治情绪当爽点 | 合规红线，也是廉价情绪 |
| 最终奖励永远是豪门、首富、总裁夫人 | 人没变，只是身份被揭穿，没有弧光 |
| "受众文化低，所以越极端越好""主题深刻是禁忌" | 和本工厂的标准相反；广电总局也点名批评"一味堆砌冲突反转" |

## 十、改编（小说、网文 → 剧本）

补 docs/09 的 C 入口。

- **重构，不是翻译**：大的走向尊重原著，每一集（条）内部重新组织。
- **压缩五法**：
  1. 冲突合并：同类冲突合成一次更大的；
  2. 时间跳跃：不演过程，直接到结果；
  3. 信息前置：先给爽点，再补解释；
  4. 删繁就简；
  5. 支线取舍：主线 80%，重要支线 15%，次要 5%。
- **三删**：删人物刻画（转成台词、动作、服装）、删环境渲染（交给美术）、删事件之间的连接（交给剪辑）。
- **原著有、但只能靠内心独白的**：转成物件、动作或空间关系；转不了就删。
- 冲突点按强度分级（三星、两星、一星），三星的必须保留，一星的先删。

## 十一、流程里的几条硬规矩

1. **交稿附"自评最不满意的一处"**：执笔人自己写出这一稿最弱的地方。写不出来，说明还没认真看，重看一遍。
2. **对标不熟就承认**：引用参考作品时，不熟的作品直接说不熟，不许编情节。
3. **冷读按问题挑视角**：冷读（`templates/冷读.md`）一次挑 3–4 个对口的视角，例如普通观众、类型老炮、挑刺的制片人、失败片导演。全员都说好时，自动追加一个专门唱反调的视角；只标出分歧在哪里，不打平均分。
4. **反向拆合**：相邻两条是同一个叙事目的，合并；一条装了两个目的，拆开。
5. **默认道具警惕**：纸条、钥匙、照片、信封这四样太常见，用作承载物时要有新的意义，否则换一样只属于这个世界的东西。
