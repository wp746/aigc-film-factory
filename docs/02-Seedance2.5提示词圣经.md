# Seedance 2.5 提示词圣经

> 本文件是整座工厂对 Seedance 2.5 的**唯一权威口径**。所有岗位写提示词、审提示词、修提示词，都以这里为准。
> 来源：即梦/Dreamina《Seedance 2.5 User Guide》官方手册快照（rev.419，2026-08-16，经 liyue-aigc 仓库整理）、Dreamina 官方 Prompt Guide / Motion Reference Guide、Higgsfield 平台参数快照（2026-09-26）、Higgsfield 开源的 95 分钟 AI 长片生产手册（Hell Grind / CINEDANCE）、goodcase.ai 207 条高热案例的实测归纳（LearnPrompt）。
> 证据分级：**【官方】** 手册/官方页明确写的；**【平台】** 某个托管平台的参数；**【实测】** 社区多案例验证过的；**【工厂】** 本工厂的约定，不是模型保证。
> 你的账号、地区、入口（即梦 / Dreamina / 豆包 / 火山方舟 API / 第三方平台）界面上能选什么，**永远以你眼前的界面为准**。界面和本文冲突时，按界面提交，并把差异记进 `projects/<项目>/logs/平台差异.md`。

## 一、先认清这台机器（能力边界）

### 1.1 硬参数【官方】

| 项 | Seedance 2.5 | 备注 |
|---|---|---|
| 标准生成时长 | **4–30 秒**（97–721 帧） | 30 秒是单次连续生成上限，本工厂的"一场戏"就按这个装 |
| 超长视频 Long Video | 30–180 秒 | **Beta/界面依赖**；不是所有入口都有；单条超过 30 秒身份漂移明显上升【实测】 |
| 视频延长 | 源视频 < 30 秒，可前延/后延；嵌套到约 60 秒 | 只描述新增区间 |
| 视频编辑 | 源视频建议 ≤ 20 秒 | 智能编辑 / 标注编辑；按源视频时长计费【平台】 |
| 分辨率 | 即梦手册：480p / 720p；Higgsfield：最高 1080p；官方营销页写 4K/Upscale | 要 4K 交付走 Upscale 或 Seedance 2.0 std 4K 通道 |
| 画幅 | auto · 21:9 · 16:9 · 4:3 · 1:1 · 3:4 · 9:16 | **画幅、时长、分辨率是界面参数，不写进提示词正文** |
| 图片参考 | 最多 30 张，单张 < 30MB，宽高 300–6000px，宽高比 0.4–2.5 | |
| 视频参考 | 最多 10 段，单段 2–30 秒，**合计 ≤ 30 秒**，MP4/MOV，24–60fps，≤200MB | |
| 音频参考 | 最多 10 段，单段 2–30 秒，**合计 ≤ 30 秒**，WAV/MP3，≤15MB | 支持纯音频参考 |
| 素材总数 | ≤ 50（首尾帧也计入） | |
| 首尾帧 | 不是独立模式，是全能参考（omni_reference）里的一种用法 | 尾帧画幅必须与首帧一致，输出画幅锁定首帧 |

### 1.2 稳定区间（比硬上限更重要）【官方】

| 素材类型 | 稳定 | 开始掉稳定 |
|---|---|---|
| 图片里的主体数 | 1–8 | 9–12 |
| 视频/音频驱动的主体数 | 1–5 | 6–10 |
| 参考视频/音频单段时长 | 5–10 秒 | 更长 |
| 编辑用参考图 | 1–5 | 6–8 |
| 多视角 | **一张图一个视角** 优于一张拼图多视角 | 超过 5 个主体时必须拆图 |

**工厂规则**：一条 30 秒生成，同框可追踪角色 ≤ 3 人【实测：跨切镜只能稳定追踪 3 人】，参考图 ≤ 8 张，参考视频 ≤ 2 段。超过就拆生成。

### 1.3 五种主模式——先选模式，再写字【官方】

| 你要做的事 | 模式 | 提示词的本质 |
|---|---|---|
| 纯文字生成 | 文生视频 t2v | 一份场景简报 |
| 用图/视频/音频生成 | 全能参考 omni_reference | **参考职责表 + 场景简报** |
| 改一段已有视频 | 视频编辑 video_edit | **编辑令**：唯一母版 + 编辑范围 + 保留清单 |
| 在已有视频前/后续拍 | 视频延长 video_extension | **边界帧契约** + 新内容 |
| 30–180 秒一次出 | 超长视频（Beta） | 分幕 + 每幕结束状态 |

专项能力（挂在主模式上，不是新模式）：首尾帧/多关键帧、多宫格分镜驱动、白模/Clay 渲染（粗模/精模）、无缝转场（两段之间生成桥）、绿幕合成、视角重建、音色绑定、去 BGM、创意迁移、局部替换。

### 1.4 2.5 相比 2.0 最该改掉的旧习惯

- 2.0 的"每 3 秒一切"→ 2.5 用 **6–8 秒叙事拍**，动作/卡点才细到 1–3 秒，**最后留 3–4 秒收束**【官方指南 + 实测】。
- 2.0 动不动塞 BGM、乱出字幕 → 2.5 官方把"不乱出字幕/BGM"列为头号修复，但你**仍然要写**声音策略。
- 2.0 的 `@图片1 完全参考` → 2.5 要写清 **每份素材管什么、不管什么、保真等级、冲突时谁优先**。
- 2.0 有 genre 参数 → 2.5 没有，类型气质写在风格段。
- 2.0 在动作段落开头写角色标签绑定表演 → 2.5 **节拍正文里写"角色名 + 一个可见标记"，不写 @标签**（标签只留在参考映射段）【实测：素材内容优先于上传顺序，正文里用标签做主语最容易一个角色变两个人】。

## 二、提示词的物理定律（违反就翻车）

这些是跨项目反复验证的"引擎规则"。审提示词时逐条引用编号。

1. **模型没有记忆。** 每次生成都是全新的。角色、地点、光、声音没写进本条提示词，就等于不存在。一致性不是设置，是**逐字重复**。
2. **只写看得见、听得见的。** "空气里有松香味"无效；"地上铺着松针，风吹动枝条"有效。
3. **情绪写成生理与行为，不写形容词。** "他很愤怒"→"下颌咬紧又松开，鼻翼张开，呼气从鼻腔短促喷出"。一次情绪转变给 **2–4 个可观察线索**就够，列满整张脸反而机械。
4. **写状态，不写过程。** 模型擅长"已经在挥拳中途"，不擅长"伸手进包、掏出刀、蓄力"。复杂动作**开场即在动作中**，接近过程另起一镜。
5. **出画即剪。** 角色离开画框，这一镜里他就不存在了。不要在一个连续镜头里设计"出画再入画"。
6. **画外即不存在。** 状态变化必须先在画面里发生过，才能在后面被引用。
7. **切镜后空间归零。** 每次切镜都要**重新声明**谁在哪、朝哪、看哪。
8. **双重反差切。** 每次切镜，景别**和**机器性格（手持/固定/稳定器跟拍/摇臂/航拍）都要变；两项都不变的切会像跳帧。
9. **反射是雷区。** 镜子、水面、刀面倒影会打碎场景几何。必须要时：把倒影本身当成独立一镜的主体，再切回实体。
10. **文字不可靠。** 招牌、屏幕、字幕、Logo、数字、品牌名都不要指望模型写对。故事关键文字留到后期合成，台词里避开品牌名和数字。
11. **肯定句优先。** 模型常把否定句当场景描述读，"不要摔倒在背上"可能真摔在背上。写"他扑倒、腹部着地"。确需禁止的已知故障（复制人、多出家具）用"**先写计数，再写禁止**"：`画面中只有一把椅子，绝不出现第二把`。
12. **不写年龄。** 任何语言的年龄词（男孩、女孩、少年、少女、年轻、孩子、22 岁……）都会让审核骤然收紧，也会让脸往低龄漂。写**身份、体格、衣着、动作**："一个穿湿透派克大衣的瘦削快递员"。
13. **左右永远以镜头为准。** 写"画左/画右"，模型不懂"角色的左边"。
14. **时间码是预算，不是剪辑点。** 动作可能落在边界前后半秒。不要要求"一秒内完成三个动作"。
15. **一拍最多三句话。** 一拍塞满，模型就把它抹平。
16. **一个镜头一个主要运镜。** 推+摇+环绕同时发生 = 镜头过载，画面会糊成一团。
17. **一次生成只干一种活。** 重物理（打斗、碰撞、液体）和重表演（眼神、呼吸、微表情）在同一次生成里会**两头都做一半**。两种活都重时，拆成两条再剪。

以下 18–24 条来自《潮水来之前》第 2 条实拍事故（2026-11）：参考图里有岛和灯塔、提示词点了 6 次"灯塔"，结果灯塔被画在镜头正前方，和前后条的地理矛盾；光变成正对镜头的太阳光团；人物落点就在机位脚下，结尾成了大脸。

18. **参考图里的地标会被搬进画面，而且比文字优先。** 上传前逐张看参考图：图里出现了本条画面中**不该出现**或**方向相反**的地标（岛、塔、窗、门、车），这张图就不上传，或换掉。宁可少一张材质参考，也不要一张带错地理的图。参考图里的天气、时段、亮度同理：图是白天阴天、本条是暴雨夜，就在职责句写"不取它的天气、时段和亮度"，并在【光照与色彩】写出画面里看得见的天气（"每一帧都看得见斜飞的密集雨线"）。
19. **画外即不点名。** 本条画面里不该出现的实体（镜头身后的灯塔、远处的岛、已被淹没的路），提示词里一个字都不写它的名字，包括"不入画""在镜头身后""没有××"这类否定句。只写它在画面里留下的效果和画框方位。每条在交付文档上传清单下写一行 `**画外禁名**：A、B`，`tools/prompt_lint.py --all` 会逐条检查。
20. **光写落点，不写光源。** 画外光源只写它照到什么、从画框哪条边进来、往哪个方向滑："一道冷白的光带从画框上沿外扫进画面，由画左向画右滑过雨幕和水面"。再加一句"画面里看不见光源本体，没有正对镜头的光团"。
21. **距离和大小写成数字。** 人物朝机位运动时，必须写她停在离镜头约几米、全身占画高约几分之几，落点不能是机位所在的位置。机位运动写米数（"30 秒后退约 7 米"），推镜距离要和起止景别算得上（中景到近景要推近一半距离，不是"不到一步"）。
22. **高度差写成数字。** 台阶、坡、楼梯写级数和总高（"约 15 级、约 3 米高"），不然模型会把它画成和路面一样平。
23. **画左画右只写在单个镜头里。** 角色锁、道具锁里不写"在画右"；正反打时同一只手会换边。方位写进每个镜头的时间轴（"他左手的马灯在他身体的画左一侧"）。
24. **拿不准的调度先做白模预演。** 满足任一条就做 `crew/25` 白模预演并作 @视频1：一镜到底里人物与镜头的距离变化超过 3 倍；有高度差的爬升或下降；地标在机位身后、画面里只能看到它的光；机位要后拉或升高到一个明确的终幅大小。预演只管结构，提示词正文写"与预演视频一致"，不用标签做主语。
25. **有预演，提示词就照预演写。** 预演的切点就是时间轴的切点；时间轴每一行写"（同预演 X–Y 秒）"，并写出与预演同一段一致的机位、高度、焦段、运镜、人物位置和朝向。文字和预演不能各说各的：预演改了，提示词跟着改；只改提示词时不许动结构。交付文档里在上传清单下放一张"预演对照"表。lint 会查每行是否对应了预演段。
26. **一镜到底要有理由，而且这个理由观众看得出来。** 长镜头不是为了省事、也不是为了怕切错，只为下面三件事之一，交付文档每条长镜头下写一行 `**长镜头理由**：视觉张力 / 情绪层次 / 推进剧情——高级点落在第 X 秒的什么画面`（lint 会查）：
   - **视觉张力**：空间、尺度或调度本身就是奇观，切开就看不出来——镜头穿过空间把两个世界连成一个、巨物的尺度随运镜一点点露出来、人在不断变化的构图里越来越小。写清镜头在哪一秒揭示什么、起幅和落幅各是什么构图。
   - **情绪层次**：情绪在不被打断的时间里一层层变（第 35 条）——切开就断了累积。写清分几层、每层脸和身体可见的变化、从哪个词开始转；机位固定或几乎察觉不到的慢推。
   - **推进剧情**：在一个镜头里完成揭示或逆转，靠调度而不是剪辑把新信息带进画面——人物走进前景、焦点从一个人转到另一个人、镜头移开露出一直在场的东西。写清揭示发生在第几秒、揭示前观众以为是什么。
   三件都说不出来，就分切：远全中近特，每个镜头只干一件事，景别和机器性格都换，机位守在轴线一侧，用特写和插入镜头给出身体、手、脚、脸（《潮水来之前》第 2 条：30 秒里跑、浪、爬、回头、揭示五件事，一镜到底就是错的）。反过来，切镜也要有理由：切给谁、为什么是这一刻（第五节）。

以下 27–34 条来自用户收集的 5 条 Seedance 2.5 出片好的提示词（巨兽实拍、韩式校园格斗、3D 松鼠追逐、功夫破墙、3D 商场喜剧，Gemini 逆向，2026-11-01）。只收工厂原来没有、又能经得起推敲的写法。

27. **角色锁死，场景只锁风格。** 角色和道具的职责句写"与参考图完全一致"；场景图的职责句写"只取美术风格、材质和色彩，不是固定构图，不作首帧，镜头可以在这个世界里自由走位"。场景图被当成首帧，镜头就转不开、推不动。和第 18 条一起用：场景图先查地标，再限定只取风格。
28. **多镜头条写一句切点清单。** 在【摄影规格】写"本条只在以下时间点硬切：4、9、13、18、21、24 秒，镜头不自行切换"。有预演时就是预演的切点（第 25 条）。这和第 14 条不矛盾：动作仍按预算写，切点用清单钉住。
29. **变速只落在切点上。** 慢动作只给一整个镜头，写倍速："18–21 秒整段 0.4 倍慢动作，其余全部实时，变速只发生在切点"。不在一个镜头中途变速，会抖、会掉帧。
30. **巨物要有比例尺。** 写巨兽、法相、机甲、巨浪时，每条至少给一个画面里的常见物做参照，写成数字或对比："被甩出约 200 米，砸进林子，树还没有它的身体高""它的脚掌比旁边的卡车还宽"。没有参照物，巨物会变成模型玩具。
31. **能量和爆炸写成次生物理。** 光束、剑气、法宝、爆炸不写"炫光""火球"，写它在环境里造成什么：冲击波压倒草和树、尘土柱向四周推开、碎石弹跳滚动、地面开裂、气浪掀动衣摆和毛发。再写一句"光不过曝，没有游戏感的炫光"。皮、甲、鳞要有磨损、灰尘、血迹和环境污渍。
32. **模型的已知误画，用正面解剖写两遍。** 东方龙会被画出翅膀、神兽会多长一条腿，就在角色锁里写正确结构（"蛇形长身、四爪、背上一排骨刺、身上没有翼"），再在出事的那一镜里重复一次。只写两处，不要在结尾堆一串"无翼、无翅膀"的标签。
33. **台词两处对齐，配乐让台词。** 台词写在时间轴的那一秒里，和动作绑在一起；【声音】里再按顺序逐字列一遍（说话人：「台词」），并写每个人的音色锁。用配乐的条加一句"配乐在台词下自动压低"。
34. **表演写分寸对照和状态链。** 情绪写成"克制的不悦，不是夸张的愤怒""打赢后不笑、不庆祝，只看得见呼吸还没平"。每个角色在【表演】里给一行状态链："岚：慌 → 拼 → 停住 → 塌下来"。动作戏加一句"贴地的真实发力，不是威亚、不飞"。

**可选（按交付平台）**：
- 16:9 出片又要切竖屏时，加一句"主体始终在画面正中的正方形区域内，可以直接裁成 9:16"。
- 跟拍速度可以写时速（"约 50 公里/小时横移跟拍"），和第 21 条的米数互补。

**不采纳的写法**：
- 结尾堆一大串正面标签"重锚定"：会撑破 5000 字上限，还会和正文打架。
- 英文负面词清单：Seedance 没有负面提示词栏，否定词会被当成描述读（第 11 条）。
- 不写时间、只写 Scene 1–7 的散文式：结果随机（第十一节），不用于付费正片。
- 照着别人的成片做"尽可能贴近原片"的复刻：版权风险，工厂只学方法。
- 年龄与人种词（young adult、Korean）：第 12 条。
- 19 刀的 20 秒微切：只适合动画追逐和喜剧，每刀只做一个动作；真人表演戏每个镜头至少约 1.5 秒。

以下 35–40 条来自用户收集的一条双人对白表演戏样本（30 秒、4 个镜头、门廊夫妻争吵、原生英语对白，2026-11-01）。它是第 17 条"一次只干一种活"的正面范例：零物理、零运镜，全部预算给脸、呼吸和声音。

35. **表演戏可以给一张脸长镜头，但要按情绪分段。** 样本把 19 秒给了女人的一个越肩近景，内部再用小时间码分成 5 段情绪：反击、自证、裂缝、破音、坦白。每段写清这几样：眉、眼、嘴、呼吸、头和手各怎么动，以及从上一段带过来的情绪残留。这是第 26 条说的"连续时间本身就是意义"：情绪在一个镜头里一层层瓦解，切开反而会断。前提是机位固定或者只做难以察觉的慢推，并且全条没有动作。
36. **表情变化钉在台词的某个词上。** 不写"她越来越激动"，写"说到 eighteen years 时鼻翼张开，身体前探几厘米""说到 my life 时加重""good 之前有一次短促破碎的吸气"。词是口型同步的锚，表情跟着词走，模型最容易对上。
37. **每句台词写语气曲线。** 写音量、语速和咬字怎么变："第一问锋利，第二问声音下降""两句之间有一次极短的吸气""句尾音量降低，像已经知道答案的疑问"。【声音】里再写一句整条的情绪轨迹，并要求"不要从头到尾同一种喊叫强度"。保留真实的换气、吞咽、鼻腔颤音和哭腔，写"不要过度降噪"。
38. **听者镜头和画外台词。** 一个人说、另一个人听的时候，可以切到听者。说话人的台词在画外继续，并写清两点：声音从听者画面的哪一侧来，以及"听者全程不说话、闭着嘴"。上一个镜头的最后一句可以写"句尾不停，声音延续到下一个镜头"，做成同一次生成里的台词跨切。听者的变化写成一个转折：防御 → 被某个词击中 → 第一次移开目光。并用分寸句收住，例如"不要让他哭出来"（第 34 条）。
39. **越肩前景写占比，回切写"同一机位"。** 越肩镜头写前景人物占画面的位置和比例（"肩和后脑虚化，占画左下角约五分之一"）。回到同一个人时写"与镜头一完全一致的方向、焦段和光线"。两人距离写数字（"面对面约一米"），轴线写清谁在空间左侧、谁在右侧，并要求"视线始终对接"。
40. **面部动作编码只能辅助，不能替代描述。** 样本在每段大白话后面附了 FACS 动作单元（AU4 眉下压、AU7 眼睑收紧、AU9 皱鼻、AU10 上唇抬起、AU25/26 张嘴）。模型能不能读懂 AU 编号没有验证，所以工厂的规矩是：先用肉眼可见的描述写全，AU 编号只作为一行补充附在后面，每段不超过 5 个。不允许只写编号。

**这条样本里不照搬的**：
- **年龄、人种词**（"50 岁左右的非裔美国男性"）：按第 12 条，改写成肤色、发质、皱纹、体格和衣着。
- **"不要……"的长清单**：改用肯定句加计数（第 11 条）。
- **台词照搬已发表剧作原文**：样本台词出自已出版的话剧和电影剧本，有版权。工厂只学结构，台词一律原创。
- **台词量**：样本 30 秒约 70 个英文词，中文对白按第 7.4 节的容量算，不要照搬这个密度。

## 三、参考素材（多参）的写法——榨干 2.5 的第一杠杆

2.5 最大的升级是 **50 份全能参考**。用好它的前提：**每份素材都要有一句职责合同**。

### 3.1 职责合同句式【官方 + 工厂】

```
<素材标签> 定义 <对象> 的 <采用哪些属性>；保真等级：<完全保留/部分保留/属性迁移到某目标/仅作气质参考>；
不要继承 <背景/构图/姿势/文字/光线/其他人物/灰色底板/拼版布局>；生效时间：<全程 / X–Y 秒>。
```

示例：

```
@图片1 定义「林砚」的脸、发型、体格与全身服装，完全保留；不要继承灰色背景、拼版边框与多视角布局。
@图片4 定义「旧书店」的空间结构、书架排布与窗光方向，只取空间与材质；不使用图中人物，不作为首帧，不继承原图构图与调色。
@视频1 只提供 18–24 秒的"侧身—冲刺—起跳"重心与节奏，映射给林砚；不继承视频里的人物、场景与其他时段动作。
@音频1 为林砚 8–11 秒那句台词提供音色：低沉、语速慢、带压住的呼吸；不继承底噪与其他说话人。
```

**素材标签**：严格照抄你所用界面显示的写法（即梦中文界面常见 `@图片1/@视频1/@音频1`，Dreamina 英文界面 `@Image 1`）。一个项目只用一种写法，不混用。

### 3.2 五步多参工作流【官方】

1. **逐个点名映射**：一行一个主体。致命错误是 `@图片1–4 分别是四个角色`——模型会猜。
2. **按类分组**：`[角色]` → `[道具]` → `[场景]` → `[动作与声音]`；角色组加互斥锁："这些角色的外貌、服装、动作、位置、台词互不交换。"
3. **常驻主体建档**：跨多场的角色，合成一个档案块（外貌=@图片1，固定道具=@图片5，出没地点，动作参考，禁止项）。
4. **按场选用**：每一场只列本场真正用到的子集。**某个主体不在这一镜，就不要出现它的标签**——写了它就会被硬塞进画面。
5. **归属检查**：道具只属于一个人；人数、服装、空间朝向全程不变。

### 3.3 角色参考图怎么做（资产端决定 50% 成败）【工厂标准：用户指定的三视图单图】

- **每个角色一张三视图单图**（16:9，连续无缝浅灰影棚背景）：
  - 左半：正面、背面两个**等大**全身像，从头顶到鞋底完整入画，双手空；
  - 正面全身像的脸处理成**柔和模糊、无五官的肤色椭圆**（否则远景时模型会从这张小脸取样，导致远景变脸）；
  - 右半：一个大尺寸**严格正面**头肩像，完整发型入画——**唯一的面部依据**。
  - 提示词写法见 `crew/19-image25-prompt-master/SKILL.md` 第一节。
- Seedance 引用语：`@图片N — 「林砚」：脸只从右侧大头像取；体型、服装、鞋、首饰从左侧正面与背面全身像取；正面全身像的模糊椭圆不是脸，不要还原它；不继承灰色背景与三视图版式。`
- 对白或强情绪戏多的角色，**另补一张强表情单图**（大笑露齿或含泪愤怒），让模型学会这张脸的动态和牙齿结构。
- 状态变体（湿透、带伤、换装）是**独立资产**，各自一张三视图、一个标签：`@林砚`、`@林砚_湿`、`@林砚_伤`。
- 三视图可以带本片的胶片质感，但光必须柔和均匀、细节清楚；戏剧性的电影光放在场景和视频提示词里，否则角色会把那套光带进每一场。

### 3.4 场景参考图

- 拍 **3/4 视角**，不要正面"漂亮图"（正面图在全景里会变成平面墙纸，画框外会每次重新发明）。
- 每个场景留**锚点物**（立柱、台灯、沙发）。"角色站在台灯旁、面朝门"能稳；"角色在房间里"是抽奖。
- **一套光逻辑**：一个主光源、一个阴影方向，绝不出现两个太阳。
- **多视角用宫格图，不用视频截帧**：以场景主图为唯一依据，用生图模型出一张 4 宫格（俯拍基准 / 正向 / 左侧 / 右侧）或 6 宫格（另加后视、鸟瞰）多视角图；每格写纵深层次、遮挡关系、材质高光、投影落点，并通过一致性审核。方法见 `crew/19-image25-prompt-master/SKILL.md` 3.2 节。
- **多人站位用站位示意图**：以主图为构图的灰色线稿 + 纯色无五官人形 + `人物 @图片N` 标签。Seedance 里写清"只取座位关系；颜色、线稿、标签不出现在画面里；不是首帧"，并逐一写出颜色与角色的对应。
- 场景参考必须写**禁继承**：`只取空间与材质，不作首帧，不继承构图、角度与调色。`

**参考优先级句**（多参考场景必写，来自用户提供的长片样例）：`人物参考图只决定外观；场景主图决定实景空间、材质与光；站位示意图只决定位置。全片是写实实拍质感，从第一帧开始。`

### 3.5 其他素材类型的职责

| 素材 | 默认职责 | 必写的禁继承 |
|---|---|---|
| 动作参考视频 | 动作、节奏、重心、走位 | 人物身份、服装、场景、画质 |
| 运镜参考视频 | 摄影机路径、速度、构图变化 | 画面内容 |
| 白模/粗模视频（可用 Blender 做） | 几何、路径、走位、机位、节奏 | 灰模材质、视口背景、坐标轴、轨迹线、相机锥体 |
| 精模视频 | 渲染指令 + 材质环境光 | 辅助线 |
| 多宫格分镜图 | 镜头顺序、构图、景别 | 线稿质感、格子边框、面板编号文字 |
| 人物三视图单图 | 脸（只取右侧大头像）、体型、服装、背面结构 | 正面模糊椭圆脸、灰色背景、三视图版式 |
| 道具状态单图 | 结构、开合方式、各状态外观、内部物件数量 | 灰色背景、并排版式 |
| 场景多视角宫格 | 空间结构、家具位置、材质、光源方向 | 宫格分格与版式；不作首帧 |
| 站位示意图 | 只取人物位置与关键道具位置（颜色↔角色对应表） | 颜色、线稿、标签、构图；不作首帧 |
| 首帧/尾帧 | 开场/结束的构图、站位、姿势、道具状态、机位朝向 | ——（每张图一句角色句，**不要合并成一句**） |
| 音色参考 | 某角色某句台词的音色、语速、气息 | 底噪、其他说话人、BGM |
| 节奏/BGM 参考 | 剪辑节拍、情绪曲线 | 不需要的人声 |

## 四、30 秒提示词的标准骨架（工厂十二段式）

由官方八段式（参考→主体→背景→时间线→镜头→风格→音频→约束）+ 95 分钟长片的 CINEDANCE 块结构 + 官方"分幕+结束状态"合并而来。**不是每段都必须写**，用不到的段删掉，不要凑。

```
【参考映射】每份素材一句职责合同（见第三节）。无素材则写"纯文本生成"。
【场景上下文】一句话：这是一场什么戏、主事件是什么、观众要看到什么变化。
               开头写人数锁：画面中只有 3 个角色：林砚、周叙、店主，不出现其他人。
【空间地图】本场的平面图，只写地点不写人：锚点物在画左/画右/后景，距离用米；
               摄影机始终在哪一侧，绝不越过哪条轴线；主光从哪来。（同场每一条生成逐字粘贴）
【首帧与站位】第一帧谁在哪个锚点、坐/站、面朝哪、看哪；道具在谁手里、什么状态。
【角色锚点】每个出场角色：名字 + 一句外观锚（与参考图一致，逐字从角色护照复制）+ 音色锁。
【光学与摄影机】每段一个焦段（视场角度数：84°/63°/47°/29°/18°/12°），段内不漂移；
               机位高度、支撑方式（三脚架/手持/斯坦尼康/轨道/摇臂）、主运镜、起止构图。
【时间轴】按"幕/拍"分段，时间连续、不重叠、总和等于时长；
               每段：起始状态 → 一个主事件 → 明确可见的结束状态。
【表演】每个角色：此刻要什么、在藏什么、身体节奏、本拍可见习惯、本段内怎么变；
               眼神任务、眨眼节奏、手上在忙什么、反应先于台词结束。
【物理】受力因果：起因 → 接近 → 接触 → 力的方向 → 身体/物体反应 → 结果 → 下一状态；
               伤痕、湿度、碎片累积保留。
【光照与色彩】真实光源、方向、色温（K）、60:30:10 主色/辅色/点缀色，同场色温不变。
【声音】对白语种声明；()音乐 <>音效 {}对白 【】字幕；环境声在先，静音策略在后；
               "只说引号里的台词，没台词的人全程闭口"。
【肯定约束】把所有禁止改写成"画面里有什么"；加一条本镜已知风险的失败判据：
               "若林砚在画面中看起来像两个人 = 失败镜头"。
```

**长度**：30 秒复杂多参提示词目标 2500–4500 字符，**硬上限 5000**【实测 babicat 规范】。超了先删：重复风格形容词 → 重复的连续性锁 → 重复的否定句 → 解释性复述 → 低优先级装饰。**永远不删**：参考职责、时间轴、主体/运镜分离、运镜起止、声音策略、结束帧。

## 五、时间轴的写法【官方】

三种时间写法，按需混用：

| 写法 | 用途 | 例 |
|---|---|---|
| 时间段 | 分配节奏预算 | `0–3 秒…3–10 秒…` |
| 时间点 | 一个关键事件 | `第 12 秒，门被风撞开。` |
| 相对时间 | 两事件间的延迟 | `她按下开关三秒后，房间的灯逐盏熄灭。` |

- 时间段**连续、不重叠、总和 = 时长**，边界写法全片统一（`0–5 秒，5–10 秒`）。
- 每段内容**不能太少**（模型会自由发挥）也**不能太多**（会过度切镜或丢事件）。
- 每段**必须有结束状态**：人物位置、道具归属、可见的场景状态。
- **一镜到底**时，时间段是表演节拍，不是剪辑点，**禁止出现"切至"**；景别变化只能靠机位或人物移动完成。
- **多镜头**时，明确写 `镜头 1（0–4 秒）… 切至 镜头 2（4–9 秒）…`，切点要写"为什么切"（说话人强调 / 听者反应 / 道具动作 / 权力反转）。
- 结尾不要写"淡出"——模型真的会淡出，白烧 2 秒；写"在 X 画面上硬切黑，不淡出、不延尾"【实测】。

## 六、摄影机语言（运镜编译器）【官方 + babicat 编译器】

每个重要节拍的运镜按这一串写，**平移、旋转、焦段、对焦、支撑、主体运动分句写**：

```
目的 → 起始构图 → 一个主运镜 → 路径/方向 → 速度曲线 → 主体走位 → 焦段/对焦 → 结束构图 → 与下一镜的衔接
```

必须区分（写错就出错片）：

| 易混 | 区别 |
|---|---|
| 摇 Pan ↔ 横移 Truck | 摇是机位不动镜头转；横移是机身平移 |
| 俯仰 Tilt ↔ 升降 Pedestal/Crane | 俯仰是镜头转；升降是机身高度变 |
| 推轨 Dolly ↔ 变焦 Zoom | 推轨有视差变化；变焦只有压缩没有视差 |
| 环绕 Orbit ↔ 主体自转 | 环绕是机器绕人走；不是人原地转 |
| 跟拍：前导/尾随/侧跟 | 镜头在主体前倒退 / 在后跟随 / 在侧平行 |

**视场角锚点**（只用这几个离散值，不写毫米、不写中间值）：

| 视场角 | 约等焦段 | 用途 |
|---|---|---|
| 107° | 14–16mm | 建筑超广、史诗建立 |
| 84° | 20–24mm | 建立、群戏调度 |
| 63° | 28–35mm | 观察、纪实 |
| 47° | 40–50mm | 中性人眼 |
| 29° | 75–85mm | 人像压缩、对白胸像 |
| 18° | 100–135mm | 近距离肖像、最保身份 |
| 12° | 180–200mm | 手、物件长焦细节 |
| 8° | 300–400mm | 极端压缩、监视感、转播 |

可量化语言：速度写 km/h，雾写浓度百分比与能见距离（20%→40%→60% 逐镜递进），白平衡写开尔文（3200K/4000K/5600K），巨物用"相当于四个人叠起来"并**让人在画里当比例尺**，冷门术语后面跟一句"可见结果"：`焦点从前景树叶平滑转到后景人物，树叶逐渐虚化，人脸由软变实。`

光圈、焦距、度数这类数值是**意图信号**，不是可执行参数——除非界面有对应控件或参考视频。

## 七、表演（让 AI 不再"塑料脸"）【实测：表演系统 + 官方情绪写法】

### 7.1 反应链

```
刺激 → 理解停顿 → 第一反应（不自主的）→ 选择后的反应 → 情绪余波 → 下一拍
```

- 先写角色的**目标、恐惧、防御、矛盾**，再写小动作。
- 每拍 1–3 个可见线索：视线转移、呼吸一滞、做了一半的手势、握力变化、姿态变化、咽回去的话、迟到的回答。
- **情绪有尾巴**：笑容慢慢褪、愤怒漏成委屈；上一拍的情绪带进下一拍。
- 矛盾情绪用两个冲动的行为表现："手指从行李箱把手上松开，又重新握紧。"
- **眼泪要累积**：呼吸变 → 眼眶湿 → 眨眼节奏变 → 指定的晚拍才落一滴。**写明"泪水不得提前出现"**。
- 脸红是可选项，慢、轻、不均匀；优先用回避视线、呼吸、说话节奏表现。

### 7.2 活眼睛（AI 表演第一破绽是死眼）

- 给眼睛**任务**："确认她眼里有没有信任""每说一句就检查有没有说中"。眼睛的动作就是表演本身。
- 眼睛先到，头后转。
- 分相眨眼：`一次慢眨 → 一次快速双眨 → 一次用力的重置眨`。
- 静态镜头的**微生命规则**：每 1–2 秒一个可见微事件（胸口随呼吸起伏、鼻翼动、眉心收放）。
- 静止写成"绷住的张力"，不要写"一动不动"（会冻帧）。

### 7.3 嘴和台词

- 唇部是高密度几何区，"抿嘴/咬紧牙关/嘴唇发抖"极易崩。**情绪交给上半张脸和颈部**（眉心、下眼睑、鼻翼、咬肌、下颌线、喉结），嘴只"自然闭合，唇形放松"。"咬紧牙关"改写为"咬肌收紧、下颌线绷住"。
- 每个不说话的人写明口型静止："双唇自然闭合，安静地听。"
- 台词只写在声音段，动作段里一个字都不要出现（否则会被念出来）。连"一个眼神仿佛在说'你也是？'"这种潜台词引号都会被念出来。
- 台词构造顺序：`声音与情绪 → 引号里的台词 → 身体动作 → 面部反应`。
- 防"轮流念稿"：设计话轮——抢话、重叠、留白、改口；口吃/停顿落在转折词、人称、对方名字上，**均匀结巴=滑稽**。
- 每条对白都写"话权切换"和"对方同步反馈"。
- **让台词自然的五个写法**（2026-11-04 学自海螺 H3 实拍对话，Seedance / 万相同样适用，详见 crew/23）：① 台词前先写一个手上的动作，模型会把动作时间演成自然停顿；② 用逗号、省略号、问号写呼吸，不写一整句平铺；③ 听者只回问对方一个词；④ 难出口的话写"声音变小"，对方追问"什么？"，再大声重说一遍，音量和情绪会跟着变；⑤ 最重的一句配一个停住的动作作情绪落点。
- 硬锁："所有人只说引号里的台词；没有台词的人全程不出声；描述里的'半声笑'只是表情，没有声音。"
- 语种声明单独一行在台词前：`对白语言：普通话，北方口音，自然口语。`
- 生僻名字给读音。

### 7.4 台词容量（30 秒能装多少话）

- 情绪化普通话自然语速 **3–5 字/秒**；争吵可到 5–6；犹豫、哭、潜台词需要更慢。
- 时间里还要扣掉：听、理解、呼吸、打断、反应、动作。
- 经验值：**30 秒一场对白戏，总台词 50–90 字为佳，超过 110 字必然赶**。
- 三秒的拍子里，台词超过 ~12 个汉字（英文 ~8 词）就会口型失步——**先砍台词**。
- 同一拍两个人同时说话会分掉口型预算：一个给台词，另一个给身体反应。

## 八、声音

### 8.1 括号语法【官方】

| 内容 | 符号 | 例 |
|---|---|---|
| 音乐 | `()` | `(低沉的大提琴单音持续)` |
| 音效 | `<>` | `<远处一声闷雷>` |
| 对白 | `{}` | `{你还留着这把钥匙。}` |
| 字幕 | `【】` | `【第一章：雨夜】` |

### 8.2 四种声音策略，选一种【官方 + 工厂】

| 策略 | 什么时候用 | 写法 |
|---|---|---|
| **干净** | 后期要配乐、要重新混音（**工厂默认**） | 先列现场声清单，再写"无背景音乐、无字幕、无旁白" |
| 纯现场声 | 纪实、恐怖、强沉浸 | 只描述画面里发出的声音 |
| 配乐 | 单条成片、MV、预告 | 写音乐的角色、进入时间、情绪 |
| 源音频迁移 | 有授权音轨要对口型 | 写明口型跟随音频里的真实人声，无人声段闭唇，只允许一个人对口型 |

- **先写正面的现场声清单，再写抑制**；抑制词不要写在 `()` 里（`(无音乐)` 可能被当成音乐指令）。
- 写混音："人声干净贴麦，环境声垫在下面，有人说话时环境声自动压低。"
- 连续对白片段要写"没有静默空档、没有旁白"，否则会给你配乐加一张在动的嘴【实测】。

## 九、生成之后：修片规程

### 9.1 先分类再修（只修坏掉的那一层）

身份/产品漂移 · 主体动作 · 运镜路径/速度 · 构图 · 碰撞/连续性 · 光/风格 · 声音/时间 · 多余文字/音乐。

能局部编辑就局部编辑；否则只改出问题的那个素材、那一格分镜、那一段时间轴。

### 9.2 外科式迭代【实测：95 分钟长片】

- **每次只改一行**，其余逐字不动。整条重写会把有效的部分一起丢掉。
- 每次生成都进 `generation-log`：版本、改了什么、结果、判决。
- **10–15 次法则**：一个镜头 10–15 个版本还不成，**问题不在措辞**——简化镜头：拆两条、删一个动作、换角度。
- 同一缺陷连续两次重抽不变 → 停止抽卡，改结构。
- 修订时永远**输出一整条完整替换稿**，不要在提示词里写"不是之前那个运镜"这种历史残留。

### 9.3 常见故障 → 根因 → 修法

| 症状 | 根因 | 修法 |
|---|---|---|
| 一个人变两个 / 双胞胎 | 正文用 @标签做主语；多视角拼在一张图；没有人数锁 | 正文改"名字+可见标记"；拆图；开头加"画面中只有 N 个角色" |
| 远景变脸 | 角色图全身像带着清晰的小脸 | 三视图正面全身像的脸改为无五官模糊椭圆，并在引用语写明脸只从大头像取 |
| 一张嘴就怪 | 参考图全是中性脸 | 补一张强表情露齿图 |
| 人物换位/镜头跳轴 | 没有空间地图；切镜后没重申站位 | 加空间地图 + 轴线 + 首帧站位；每次切镜重申 |
| 角色乱说话/嘟囔 | 台词短于镜头时长，模型填空 | 加"只说引号内台词"锁；给其他人写闭口状态；缩短镜头或加长台词 |
| 动作没完成就切了 | 时间预算不够 / 动作在中段 | 减事件；复杂动作放开头；结果单独给时间 |
| 手在动东西不动 | 只写了手的动作 | 写机制：手指扣住盖沿 → 盖子转开 → 盖子离开瓶口 |
| 打得软、脸也平 | 物理和表演挤在一次生成 | 拆成两条：一条管物理、一条管表演 |
| 结尾两秒发黑 | 写了"淡出" | 写"硬切黑，不淡出" |
| 冒出字幕/BGM | 没写声音策略 | 写现场声清单 + 抑制句 |
| 群众时多时少 | 没给数量 | 写"20 人以上的人群作为一个整体向左涌动"，只追踪 ≤3 个个体 |
| 巨物变小 | 没有比例尺 | 尺度对比 + 人在画里 + 失败判据 |

## 十、提交前十七问（每条提示词都过）

1. 主模式选对了吗？时长/画幅/分辨率在界面里设了、没写进正文？
2. 每份素材都有职责、保真等级、禁继承？标签与上传顺序一致？
3. 本镜不在场的主体，标签删干净了吗？
4. 开头有人数锁吗？
5. 有空间地图、轴线、首帧站位吗？
6. 每段一个焦段、一个主运镜、有起止构图吗？
7. 时间段连续、无重叠、总和等于时长？每段有结束状态？
8. 台词总量在容量内？每句有说话人？其他人闭口？语种声明了？
9. 情绪全部写成可见行为？有眼神任务？泪/笑/怒有累积过程？
10. 物理动作有完整因果链、在正确顺序上？
11. 声音策略只有一种、不自相矛盾？
12. 没有年龄词、没有反射镜头、没有关键文字、没有"淡出"、没有否定句陷阱？字数 ≤ 5000？
13. 复杂度预算是绿色吗？黄色有替代方案吗？（`docs/06` 杠杆 4）
14. 该有的图都有了吗（设定图、场景图、道具图、需要时的首帧图）？
15. 开头有一句梗概 + 必演节拍清单吗？结尾是剪辑指令吗？
16. 长镜头写了理由（视觉张力 / 情绪层次 / 推进剧情）和高级点落在第几秒吗？多镜头条写了切点清单吗？慢动作是整镜、写了倍速吗？巨物有比例尺吗？场景图只锁风格了吗？（第 27–30 条）
17. 克制测试：删掉电影感、器材名、分辨率、颗粒这类词以后，剩下的字还写得清故事、机位和有来源的光吗？（docs/06 第六节）

## 十一、社区实测补充（awesomevideoprompts 135 条 Seedance 2.5 案例）

详见 `docs/06-一次成片方法论.md`（降抽卡、故事/节奏/质感控制、选型速查）和 `docs/07-30秒以上长片衔接.md`（分镜拼接、关键帧续写、原生延长、故事板预览）。要点：

- **结构**：时间码分镜型占 44%，是剧情和动作的主力写法；叙事散文型（30%）结果随机，不用于付费正片。
- **故事**：开头一句梗概 + 边界句；必演节拍清单；给镜头起标题；伏笔在第一帧就在场；结尾写硬切。
- **节奏**：小数秒时间码；全片速度声明或逐镜变速百分比；每镜单独写声音；"突然 → 停住"；调色跳变 + 声音截断的硬切。
- **质感**：先声明拍摄介质（35mm 某年代电影 / 2000 年代 DV / 手机随手拍 / 黑白硬光），再写介质带来的瑕疵；调色按时空分段；色彩纪律（特效颜色不染全片）；天气与面料写成物理量；浅景深按叙事选，不滥用。
- **一致性**：参考映射写冲突优先级；分段时角色块与画风块逐字重复；每个实体一行连续性状态；伤与损坏继承；尺度锁；背景人物环境化。
- **对第二节第 12 条的说明**：社区案例里 49/135 写了年龄词（"17 岁""teen"）也出了片。工厂仍然不写——年龄词会让审核骤然收紧，也会让脸往低龄漂，一次被拦就是一次白花的钱。
