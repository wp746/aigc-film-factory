# 19 · 分镜数据格式（设定.json + 分镜.json）

> 剧本确认后，智能体唯一要"写"的东西就是这两份 JSON。机位坐标、"画面里"那句话怎么写、说话人怎么写、群演怎么点名、过肩选哪一侧、每条带哪些参考图，全部由 `tools/storyboard.py` 按固定规则算，所以**同一份数据，任何智能体跑出来都一样**。
> 标准样例：`examples/样例-便利店/`（剧本 `03-剧本.md` → `设定.json` + `分镜.json`）。动手前先读一遍样例，照它的写法拆。
> 写完跑 `python3 tools/storyboard.py check projects/<项目>`，每条 ERROR 后面都写了怎么改，改到"通过"为止。

---

## 一、拆剧本的固定步骤（照顺序做，不跳）

1. **列人物**：剧本里有名字、有台词或有特写的人，进 `characters`；没名字的路人不进，进群像。
2. **列场景**：每个地点一个 `location`，给它搭一个简单白模（地面尺寸 + 几个方块）和站位点 `marks`。
3. **列道具**：剧情要靠它推进、会被特写的物件，进 `props`。
4. **列群像**：每个有路人的世界一张群像，14 人，每人写身高（docs/17）。
5. **分条**：每条 4–30 秒，一条只在一个地点，一条只拍一组对话（一条轴线）。**时长按内容定，不凑满 30 秒**（docs/20 第四节）；放不下就拆条。
6. **分镜**：剧本里每个【】一镜，按第三节的字段填；台词照抄剧本，一字不改。
7. **跑 check**，按 ERROR 改，直到通过。


| 镜头字段 | 说明 |
|---|---|
| `dur` | 秒，≥ 1.5；全条加起来 4–30 |
| `type` | `wide` 全景（用 establish 或 `view`）· `single` 单人 · `ots` 过肩 · `insert` 物件插入 · `track` 跟拍 · `pov` 主观 |
| `size` | 大特写 / 特写 / 近景 / 中景 / 全景 / 大全景（决定焦距和机位距离） |
| `subject` | 拍谁（single / ots / track / pov 必填） |
| `fg` | 过肩越过谁的肩膀（ots 必填）；一条里只能有一组 fg–subject |
| `who` | 画面里另外还有谁（wide 必填） |
| `object` / `hand` | insert 拍哪个 mark；有动作就必须写 `hand`：谁的手、什么样、袖口；确实没有手写 `no_hand: true` |
| `look` | pov 看向哪里 |
| `view` | wide 用哪个固定机位（stage.views）；9:16 时会自动转、换焦段、后退，把 `who` 里的人装进画面，写 `"keep_view": true` 就原样用（docs/22 第七节） |
| `line` | `{"who": 说话人, "text": 台词, "mode": "on|back|off", "delivery": "压低声音、说到一半停住"}`；on = 在画里说，back = 过肩前景背对镜头说，off = 画外；**有台词的镜头必须先写一个手上动作**，台词用标点写出呼吸（crew/23 让台词像人说的五条） |
| `action` | 一句中文，或 `{"at": 秒, "text": …}`；**有台词的镜头最多一个动作** |
| `sound` | `[{"text": "推门的风铃声", "source": "门口"}]`；source 是画里的发声者、站位，或 `"画外"` |
| `crowd` | `{"ids": [2, 5, 9], "doing": "在门外躲雨，陆续走开"}`；动作里写到路人就必须点编号 |
| `move` | 有动机的运镜：`{"kind": "push|pull|truck_left|truck_right|rise|drop|orbit_left|orbit_right|handheld", "speed": "slow|steady|sudden", "why": "动机", "amount": 0.4, "to": "（可选）结束景别，如 近景", "follow": "（可选）跟随目标，如 双臂攻防交错的方向", "follow_en": "…"}`。`follow` 写进提示词（"镜头跟随……"），打戏里写清跟哪个部位，比"跟随拍摄"准。程序按起始机位自动算终点（推拉走掉机位到主体距离的 amount，横移 / 升降 amount × 距离米，环绕约 35°×amount/0.4），白模几何检查会查起止两端的构图；中文写成"镜头缓慢推近"，英文写成 "the camera pushes in slowly"。`why` 必填；track / pov / cam 自带运动，不能再加；`sudden` 单镜不短于 2 秒。白模里运镜起步和收尾自动缓入缓出（像真的轨道和摇臂），`steady` 保持匀速 |
| `hit` | 武戏：`{"support": 支撑, "force": 发力, "contact": 接触, "reaction": 受力, "result": 结果, "en": 英文一句, "weight": "L1|L2|L3|L4"}`。动作里出现打、踢、砍、摔、撞、追等词时必填（crew/17 逐击五步因果），写进提示词的"动作因果"。`weight` 可选：力量档（L1 轻 → L4 终结），校验器用它查"最重一击的位置""重击后有没有反应镜" |
| `speed` | 可选，动作镜头的速度档：`静 / 慢 / 常速 / 快 / 极速`（crew/17 第 5 节）；同一档连续超过 2 镜提醒；`慢` 镜总时长超过动作段的 12% 提醒 |
| `acting` | 可选，表演三轴（crew/08）：`{"pressure": 1–5, "amplitude": 1–5, "control": 1–5, "leak": "高控制高压力时，泄漏在哪（下眼睑一跳、喉结滚一下）", "leak_en": "…"}`。压力和幅度的差就是微表情空间；control ≥ 4 且 pressure ≥ 4 时必须写 leak，否则提醒。leak 会写进提示词这一镜的动作 |
| `vfx` | 特效：`{"source", "direction", "scale", "speed", "medium", "light", "decay", "en"}` 七要素。动作里出现爆炸、火焰、魔法、能量、光束、变身、闪电、发光等词时必填（crew/18），写进提示词的"特效" |
| `center` | `true` 时这一镜不做黄金分割偏移，人物居中（默认单人中景 / 近景 / 全景和过肩都把人头放在 38% / 62%，docs/21 第五节） |
| `cam` | 逃生口：`{"pos": …, "look": …, "lens": 50, "end": …}` 直接给机位（只在规则算不出想要的机位时用）；有 `end` 且 look 是固定点时白模缓入缓出，盯着移动的人或道具（look 是人名或 `prop_…`）保持匀速，`"ease": false` 关掉 |
| `allow_occlude` / `allow_small` | 有意的遮挡 / 有意拍得很小的人（几何检查放行；"前景占掉半个画面"不放行） |
| `beats` | 精准白模：`[{"t": 镜内秒, "who": 人, "do": 姿态, "target": "人名.右手 / 站位点 / 道具", "dur": 秒, "hold": true, "text": "写进提示词时间轴的一句"}]`，或道具节拍 `{"t", "prop": 道具, "do": "take|put|move|swing|show|hide", "to": …}` |
| `aim` | insert 对准人身上的点：`"秀英.脚"` / `"秀英.手"`，取这一镜中间时刻的位置（人在走、被拖时静态 mark 会对空） |
| `cam_offset` | insert 机位相对 object 的偏移 `[x, y, z]`（默认 `[0, -0.45, 0.6]` 俯拍） |
| `cam.look` 写 `"prop_道具"` 或人名 | 盯住移动的道具或人；`look_off: [x, y, z]` 偏开一点（拍轿子前沿；盯人的脚写 `[0, 0, -1.2]`） |
| `aim_t` | insert 的 `aim` 取这一镜里哪个时刻的位置（0–1，默认 0.5） |
| `allow_exit` | 这一镜里有意跑出画面的人（"扭头就跑"）：后半段出画不算错 |

clip 级的白模字段（精准白模，docs/14）。**时间可以按镜头写**：`"镜3"`（第 3 镜开头）、`"镜3+1.2"`、`"镜3-0.5"`（第 3 镜结束前 0.5 秒）、`"镜3末"`；改镜头时长时走位跟着镜头走。同一时刻写两个位置 = 切点上换了地方（前一个提前一帧）。

| 字段 | 说明 |
|---|---|
| `extras` | 群演组：`{"ids", "formation": "line|rows|column|ring|scatter", "spacing", "at" 或 "path", "face", "face_until": 时间（之后朝走的方向）, "poses", "ahead": 米（抬轿时前一组正数、后一组负数）, "ahead_until": 秒, "world": "借用哪个世界的群像（只用于远景小点）"}` |
| `prop_states` | 道具初始状态：`{"at" 或 "path", "open": "+x|-x|+y|-y"（壳子去掉一面）, "open_at": 秒, "tear_from": 秒（帘子到点裂开）}` |
| `effects` | 特效代理：`{"kind": "debris|split|fall|sweep|reach", "t0", "t1", "at", "to", "color": BOXCOLOR 名, …}`；debris 碎石跳（radius / count / height / scale）、split 裂缝张开（width / height / depth）、fall 纸屑落（area / height / count / speed）、sweep 影子扫过（area，从 at 移到 to）、reach 巨物的臂伸过去（thick，`back: [开始缩, 缩完]`） |

## 三·五、要出海螺 H3 时补的英文字段

海螺 H3 官方提示词是英文分段格式（docs/13 第六节）。项目 `production.json` 的 `video_models` 里有 `hailuo` 时，校验器会要求下面这些英文，**写一次，编译器原样使用，不临场翻译**：

| 位置 | 字段 |
|---|---|
| 设定.json | `music_en`（没有配乐写 "N/A"）；每个人物 `voice_en`（音色：性别、音调、语速） |
| 每条 | `summary_en` |
| 每镜动作 | 写成 `{"at": 1, "text": "中文", "en": "English"}` |
| 每镜声音 | `{"text": …, "en": …, "source": …}` |
| 群演 | `crowd.doing_en` |
| 插入镜头 | `object_en`、`hand_en` |

台词不用翻译：H3 官方要求台词保留原文，编译器写成 `<d>[Chinese] 台词</d>`。

## 四、校验器会拦什么（全部是实拍或白模里踩过的坑）

| 拦什么 | 来源 |
|---|---|
| 没写故事内核 core，或内核里有等救主结构（认亲、系统、战神、赘婿、跪地求复合……） | docs/20 第一、三节 |
| 每条没写价值翻转 turn 或视听高光 signature | docs/20 第四节 |
| 场景缺锚点物 / 光逻辑 / 时代锁 / 使用痕迹；人物缺剪影识别点；被操作的道具缺操作机制 | crew/06、07 |
| 人物描述写了毛孔、瑕疵、颗粒 | docs/16（出图模型会画成砂纸皮肤） |
| 对白镜头没有动作；长台词没有停顿 | crew/23 |
| 每条没写压力源 tension；场景没写对冲 contrast；运镜没写动机 why | docs/20 第四节"张力" |
| 全片能量最高不到 4、全片只有一两档能量；每条都低能量收尾（提醒）；三条以上没有加速段（提醒） | docs/20 第四节"张力"，《最后一次采血》复盘 |
| 对手戏没写 drama，或优势易手那句给了全景 | crew/22 |
| 动作里有打斗词却没写 hit 五步；有特效词却没写 vfx 七要素 | crew/17、18 |
| 同一场连续的两条，人物站位没接上（又没写 time_jump） | crew/12、docs/07 |
| 节奏四平八稳：镜头时长最长不到最短的 1.5 倍；整条全是固定机位又没写 stillness；相邻两镜类型和景别都一样；一条不到三种景别（提醒） | docs/20 第四节"张力"、docs/14 第三节 |
| 描述锁写了岁数、年龄词 | 合规 + 第 1 版小雷"像孩子" |
| 说话人不在画里又没写 back / off | 台词串人 |
| 台词超过 4.5 字/秒 | 说不完 |
| 有台词的镜头塞了多个动作 | 第 1 条"光环闪、弹光环"被忽略 |
| 插入镜头有动作却没写是谁的手 | 第 1 条拇指变成别人的食指 |
| 动作写到路人却没点群演编号 / 没有群像 | 第 1 条长廊没人 |
| 声音没写声源 | 第 1 条长廊没声 |
| 一条里过肩换了两组人 | 越轴 |
| 站位、人物、道具、机位名字写错 | 漏读误读 |
| 镜头短于 1.5 秒、全条超过 30 秒 | 模型做不出 / 超出上限 |

**剧本层的提醒（4.0 alpha.9，docs/23）**：core 没写 promise / dilemma；连续三条同一个 `tag`；同一条里连续三句台词字数相近（节奏死板）；台词里有灌输句式（"你忘了吗""还记得……吗""三年前"、自报家门）。剧集另查 `hook_type` 和 `tag` 的重复（docs/22 第四节）。

**打戏的提醒（4.0 alpha.9，crew/17）**：同一速度档连续超过 2 镜；慢镜超过动作段的 12%；最重一击（`hit.weight` 最大的那一镜）不在动作段的 70–92% 处；L3 以上的重击是一条的最后一镜、后面没有反应镜；表演三轴高控制高压力没写 leak。

**只提醒、不拦的（4.0 起）**：画面里的文字、镜子和倒影、人物交叉、一镜内换光、多人同一秒做同一个动作、一镜动作超过两个、3 秒以上什么都不动的镜头（Eian 实测的 AI 弱点，docs/14 4.2）；类型卡和时长档位不符（docs/21）。

几何检查（Blender 白模里）再拦：主体不在画里、被挡住、太小、头后竖直物、机位穿墙、越轴、过肩前景出画。WARN 也拦。

## 五、自测

任何智能体、任何机器第一次用本仓库，先跑：

```
python3 tools/pipeline.py selftest examples/样例-便利店
```

不花钱（占位图），从样例数据一路跑到四个模型的投喂包，再和 `examples/样例-便利店/标准产物/` 逐字比对。不一致就说明环境或代码被改坏了，先修好再生产。改了框架代码、确认新产物正确时，才用 `--update` 更新标准。
