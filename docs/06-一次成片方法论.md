# 一次成片方法论（降低抽卡次数）

> Seedance 2.5 很贵，抽一次就是一次真金白银。本文写的是怎样让交出去的提示词**第一次生成就能用**。
> 来源：awesomevideoprompts.com 上全部 135 条 Seedance 2.5 社区案例（2026-10 抓取，逐条做了结构统计，其中 20 余条精读）、探路AI《如何生成30秒以上AI视频》、本工厂已有的官方手册与长片手册。
> 先说清楚：社区帖子展示的都是作者挑出来的最好一条，没有人公布自己抽了几次。所以本文里的"有效"指的是**写法反复出现、结构可解释**，而不是测出来的命中率。

---

## 一、先算清楚：抽卡从哪里来

一条视频失败，原因只有三种：

| 来源 | 能不能消除 | 本工厂怎么处理 |
|---|---|---|
| **模型随机性**（同一提示词每次结果不同） | 不能 | 用参考图、首帧把随机空间压小 |
| **指令歧义**（模型不知道你要哪一种） | 能 | 结构化写法、职责合同、计数锁、结束指令 |
| **任务超载**（要它一次做太多事） | 能 | 复杂度预算、拆条、把难的东西挪到后期 |

后两种占了大部分废片，而且全都能在**花钱之前**解决。所以"一次成片"的本质不是写出神奇的咒语，而是**在生成前把歧义和超载清零**。

**交付承诺的口径**：工厂不承诺"零重抽"（模型随机性消除不了），承诺的是：
- 每条提示词交付前都过复杂度预算，红色风险不交付；
- 每条提示词附"风险等级 + 最可能失败的点 + 失败后改哪一行"；
- 第一次生成的结果至少能进入"局部可用"（审片 ≥15 分），通常能直接入选。

## 二、降抽卡的九个杠杆（按性价比排序）

### 杠杆 1：图比字稳——先用便宜的图锁住贵的视频
文字描述一张脸，模型每次都要猜；给它一张图，它就不用猜了。生图比生视频便宜一到两个数量级。
- 角色：**三视图单图**（16:9：左半正面+背面等大全身、正面脸为无五官模糊椭圆；右半严格正面大头像，是唯一面部依据）。社区高质量案例、95 分钟长片手册和用户提供的长片样例都指向同一个原理：全身像上不能有清晰的小脸，否则远景会从它取样而变脸。
- 场景：无人主图 → 由主图推出 4/6 宫格多视角；多人场景加站位示意图（纯色人形 + 编号标签）。
- 道具：道具状态单图（关闭/打开等状态并排），写清计数。
- 全部资产提示词与 Seedance 引用语汇总在《资产提示词总册》（`templates/资产提示词总册模板.md`）。

### 杠杆 2：首帧图——把最大的随机量一次锁死
构图、光线、色调、人物站位、服装状态，一张首帧图全管了。社区里最稳的长案例都先做一张"开场钩子帧"，再把它作为第一参考，并写明"@图片1 决定开场构图、姿势、光与机位"。
- 首帧图用生图模型反复改到满意，成本远低于反复生成视频。
- 首帧图与参考图冲突时，提示词里写清谁优先："站位、光线、场景以 @图片1 为准；脸与服装以 @图片3 为准。"

### 杠杆 3：故事板预览——用一张图的价钱审完整条片子
（探路AI 方法三）先用生图模型生成一整张故事板：每场一格，格内放**首帧/尾帧**两张小图，下面写 镜头/焦段→运动、剧情一句、台词或旁白；页面底部放**主色卡（色值）**、字体、音乐与音效、交付规格。
1. 看故事板，找分镜错误（顺序、站位、视线、景别重复）——这一步只花一张图的钱。
2. 用故事板生成一张"角色+场景"中近景图作为风格与身份锚点。
3. 裁掉分镜画面，只保留色卡、声音等设定区作为参考。
4. 用锚点图 + 基础设定 + 风格 + 画面描述 + 色卡去生成视频。
- **不适合**：打斗、人多的场面。**适合**：节奏慢、两个主角的剧情片、广告片。

### 杠杆 4：复杂度预算——超预算的条目不准交付
每条生成算一次分，红色必须拆条或简化（`tools/prompt_lint.py` 会自动估算）：

| 风险项 | 绿 | 黄 | 红 |
|---|---|---|---|
| 同框可追踪角色 | ≤2 | 3 | ≥4 |
| 镜头数（30 秒，剧情戏） | 4–7 | 8–10 | ≥11（蒙太奇/动作除外） |
| 台词总字数（30 秒） | ≤60 | 61–90 | >90 |
| 同时说话的人 | 1 | — | 2 |
| 物理事件（碰撞、破碎、液体、爆炸） | ≤2 | 3–4 | ≥5 且同时有重表演 |
| 形变/变身/VFX 主事件 | 0–1 | 2 | ≥3 |
| 画面里要读懂的文字 | 0 | — | ≥1 |
| 镜子/水面倒影作主体 | 0 | — | ≥1 |
| 人群 | 无/环境化 | 有数量 | 人群中个体有动作戏 |
| 一个镜头里的主运镜数 | 1 | 2（一主一辅） | ≥3 |

### 杠杆 5：低清先验结构（看界面计费）
社区里有作者分段写提示词时，每段都标"先出 480p"。如果你的入口低分辨率计费更低：
- 先用 480p 验证**结构**：镜头顺序、站位、动作有没有完成、有没有多人多物。
- 结构对了，同一条提示词再出高分辨率。
- 注意：没有固定种子，高清版不会和 480p 版一模一样。低清验证的是**提示词**，不是那一条具体的镜头。所以低清阶段只看结构问题，不看脸和质感。

### 杠杆 6：结构化写法——让模型没有选择的余地
从 135 条案例归纳出最稳的写法（详见第四节）：顶部一句故事梗概 + 必演节拍清单，全局块（每个镜头都适用），参考映射（含优先级），带小数秒的时间码分镜，每镜单独写声音，最后写结尾剪辑指令。

### 杠杆 7：短而不赶
- 表演镜头至少 2.5 秒；**插入镜头/冲击镜头**可以短到 0.3–1.5 秒，但只能有一个可见事件（枪口一闪、杯子落地）。
- 社区有 30 秒塞 15 个 2 秒镜头的成功案例，前提是每个镜头只做一件极简单的事、几乎没有台词（蒙太奇型叙事）。剧情对白戏仍然是 4–7 镜。

### 杠杆 8：一条只干一种重活
重物理（打斗、追车、灾难）和重表演（眼神、哭、对白）分到两条生成里，剪辑时再合。社区动作片之所以成功率高，是因为它们几乎不要求细腻表演；情绪片之所以稳，是因为几乎不要求物理。

### 杠杆 9：把模型做不好的事挪到后期
文字、Logo、价格、数字 → 后期合成；配乐 → 后期（生成里写"无背景音乐"）；旁白 → 后期配音更可控；变速 → 能在剪辑里做的慢动作就不要求模型做；画面里的屏幕内容 → 后期贴屏。

## 三、社区 135 条案例的分类

### 3.1 按提示词结构（统计全部 135 条）

| 类型 | 条数 | 能控制什么 | 何时用 | 一次成片风险 |
|---|---|---|---|---|
| **时间码分镜型** | 60（44%） | 故事顺序、节奏、景别 | 剧情戏、动作戏、广告 | 低（写对的话） |
| **叙事散文型** | 41（30%） | 氛围、大意 | 情绪片、风景、简单单镜 | **高**：镜头数、节奏全交给模型 |
| **一镜到底型** | 19（14%） | 空间连续、运动路径、变身过渡 | 追逐、穿越转场、长镜头情绪戏 | 中：路径必须写得具体 |
| **参考复刻型** | 11（8%） | 动作编排、镜头顺序、节奏 | 有参考视频时 | 最低：动作由视频决定 |
| **多段续写型** | 4（3%） | 超过 30 秒的连续性 | 长片 | 中：靠续写起点和资产锁 |

**建议**：付费正片一律用时间码分镜型、一镜到底型或参考复刻型。叙事散文型只用于你能接受随机结果的情绪空镜。

### 3.2 按内容类型（标签统计）

| 类型 | 案例数 | 社区的成功写法 | 本工厂建议 |
|---|---|---|---|
| 动作/打斗 | 58+ | 先交代地形和三方站位；每击写受力结果；"环境破坏要保留" | 用结构 D；打斗与表演拆条；冲击插入镜可短于 1 秒 |
| 奇幻/VFX | 35 | 特效有源头、方向、衰减；尺度靠人做比例尺；"特效由接触或受力产生" | 每条最多一个主 VFX 事件 |
| 喜剧 | 25 | 每一拍落在一个看得见的笑点上；"正经地演荒诞"（deadpan） | 镜头标题化（每镜一个笑点名字） |
| 剧情/情绪 | 20 | 反转写成具体画面；用调色区分现实/回忆 | 结构 A/B；台词少；表演块完整 |
| Vlog/怀旧/伪纪录 | 20+ | 声明拍摄设备 + 设备瑕疵清单；"不要商业感" | 质感最稳的一类，适合低成本试水 |

| 动画/动漫 | 15 | 画风写成可测量参数 + 排除相邻画风 | 每段重复完整画风块 |

## 四、控制故事：让模型讲你的故事，而不是它的

1. **开头一句完整梗概**：谁、在哪、发生什么、怎么结束，再加一句边界："没有多余情节""没有枪声"。高质量的情绪案例（废墟厨房那条）开篇就是一段梗概 + 边界，模型知道整条弧线，就不会中途跑题。
2. **必演节拍清单（RUN ORDER）**：在时间轴之前列出"共 N 个镜头，必须按顺序全部出现，第 X 秒后属于最后一镜"。这是防丢节拍最有效的一句。
3. **给镜头起名字**：`镜头 3（3.9–4.8 秒）— 蓄力`。名字本身限制了这一镜能装多少信息。
4. **反转写成画面**：不是"出人意料"，而是"三处红光不是变亮，而是同时熄灭"。
5. **伏笔在第一帧就在场**：后面要用的东西（锁链、巨兽、钥匙）开场就出现在画面里并写明位置；"它不是临时从地下冒出来的"。模型不会凭空无缝地加东西，但会自然地让已经在场的东西发生变化。
6. **一镜一个可见事件**：写"看得见的变化"，不写解释。
7. **结尾是剪辑动作**：`在 X 画面上硬切黑，不淡出、不延尾`。社区里写"淡出"的有 19 条，这是白白烧掉最后两秒的常见写法。

## 五、控制节奏

1. **小数秒时间码**：`0.0–2.0 / 2.0–3.5 / 3.5–4.5`。节奏就是时长分配，写到 0.1 秒，模型就知道哪里快哪里慢。
2. **全片速度声明**：二选一写在全局块——"全片正常速度，无慢动作、无变速"；或在具体镜头写"慢动作（约 30–40% 速度）"，并在结尾列一份"变速清单"。不写的话，模型会随手加慢动作（社区 33 条主动写了慢动作，很多是为了控制而不是为了好看）。
3. **每镜单独写声音**：声音是节奏的发动机。"风声突然消失 → 低沉的静默 → 一声轻响"，比任何运镜都更能制造停顿和爆发。
4. **动静反差**：热闹 → 突然静止 → 停住（hold）。"突然"（sudden）和"停住"（hold）是社区里最常用的两个节奏词。
5. **镜头数不均匀**：快段落多镜短镜，慢段落一镜长停；三幕的镜头数刻意不同。
6. **硬切的力量**：冷灰现实一帧硬切成暖金回忆，声音同时切断——"调色跳变 + 声音截断"是最有冲击力的单个剪辑。

## 六、控制高级影调与质感

**最强的质感杠杆是声明"拍摄介质"，不是堆形容词。** 介质决定了一整套瑕疵，瑕疵带来真实：

| 介质声明 | 连带写出的瑕疵/特征 | 适合 |
|---|---|---|
| 35mm 胶片 / 某年代电影 | 细颗粒、高光溢出（halation）、实景搭景、实体特效、变形宽银幕镜头 | 类型片、年代片 |
| DV 摄像机（2000 年代初） | 自动对焦来回找、曝光跳变、手持抖动、褪色、轻噪点、机身操作声 | 青春、回忆、伪纪录 |
| 手机随手拍 | 强手抖、对焦呼吸、数码变焦伪影、内置麦克风收音、风噪 | 超自然、灾难、病毒视频 |
| 黑白高反差 | 单一硬主光、身体快门清晰、只有头发运动模糊、细颗粒 | 舞蹈、艺术短片 |
| 大画幅数字电影 | 自然肤色、高光过渡、空间层次 | 史诗、奇幻真人 |

其他质感控制：
1. **调色即叙事**：现实一套（冷、低饱和、低调、压暗部），回忆或另一个时空一套（暖、逆光、柔），在全局块里分开写，并标明时间段。
2. **光有来源**：窗光、荧光灯、台灯、火光、霓虹，写清楚是哪个光源、从哪边来。
3. **色彩纪律**：写明哪些颜色必须保持本色——"火焰保持正常橙色，雷电保持蓝白色，不把整个画面染成蓝色或橙色"。这一句能防止特效把整片调色带跑。
4. **天气与材质写成物理量**：风速 20–25 km/h、阵风间隔、沙尘浓度；不同面料不同反应（棉麻会鼓起来，粗羊毛只在边缘翻动）。这类写法让画面"有空气"。
5. **真实皮肤与不修饰**：毛孔、雀斑、汗光、灰尘；"无美颜磨皮、无商业光、无风格化"。
6. **浅景深不要全片滥用**：社区 135 条里有 53 条写了浅景深，它已经是 AI 片最常见的"假高级"。按叙事选：人物与环境分离时浅，人物属于环境时深。
7. **删掉空词**：删掉"8K、大师级、超高清、电影感"之后，画面应该依然具体。
8. **克制测试**（2026-11-07，造梦师 2.1）：把电影感、器材名、分辨率、颗粒这类词全删掉，剩下的字还能写清楚故事、机位和有来源的光吗？写不清，说明提示词靠的是空词，不是画面。`tools/prompt_lint.py` 会提醒空词。全片影调 `film_look` 是例外：一行、全片逐字一样的摄影机 + 镜头组 + 调色规格是影调锚点，不是空词（docs/16 第六节；《好日子》质感复盘：删光器材语言后画面落回旅游照）。
9. **受控的脏只选一个家族**：锈、水渍、积灰、烟熏、油污，一场选一种为主，不要每样都脏一点（脏得平均就像滤镜）。
10. **三个镜头里两个稳定、一个特殊**：两个稳定镜（光和构图都在规则里）加一个特殊的插入镜（特殊的光、特殊的角度）；特殊光要有画里的实体来源。

## 七、人物、场景、道具不漂移

1. **参考映射写优先级**：每张图管什么，冲突时谁赢。"姿势、光线、场景冲突时以 @图片1 为准。"
2. **角色块逐字重复**：分段提示词时，每一段都把完整的角色描述原样再写一遍，一个字不改。社区那条 90 年代动漫分段案例就是这么做的，每段同一段画风块也原样重复。
3. **连续性块按实体写状态变化**：每个人、每件道具一行，写它在哪个时间点发生什么变化——"帽子在撞车时掉落，最后一镜回到头上或拿在手里"；"购物车全程完整无损"。
4. **计数与归属**：只有一把、只有一个；属于谁。
5. **场景要素开场即在**：入口方向、主轴线、关键地标在第一帧就建立；"从南门进，沿广场中轴向北"。
6. **伤与损坏继承**："敌人的武器、倒地、破甲和场景损坏全部继承，不重置。"
7. **尺度锁**："巨兽、龙、人物尺度稳定，不能为了同框而任意缩放。"
8. **背景人物环境化**："只在远处有少量模糊的路人，从不靠近镜头。"
9. **相机朝向系统**（复杂运镜时）：定义参考帧的镜头方向为 90°，右转减、左转加，用角度描述摇镜和甩镜。

## 八、按创作意图选型（精准建议速查）

| 你想做的 | 结构 | 首选控制手段 | 关键句 |
|---|---|---|---|
| 两人情绪对手戏 | B 五镜头 / A 一镜 | 首帧图 + 角色设定图 + 表演块 | 只说引号内台词；泪水不得提前出现 |
| 一个人的情绪独白 | A 一镜到底 | 首帧图 + 连续表演时间轴（以画框左右为方向） | 时间点写到 0.5 秒；手与下半身保持在画外 |
| 打斗 | D 动作段落 | 参考动作视频或白模；三方站位图 | 受力结果写清；环境损坏保留；表演拆条 |
| 追逐/逃亡 | 一镜到底 | 路径地标 + 机位相对位置 | 只有一个主运镜；不切；物体不瞬移 |
| 时空穿越/转场 | 一镜到底 + 变换规则 | 每个过渡点用"脚下材质延续"串联 | 人物不溶解、不复制、不变尺度 |
